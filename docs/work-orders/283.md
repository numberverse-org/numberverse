# #283 — Goal badges (10 rounds, 100% day)

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

No small, collectible trophies for learning wins. Acceptance: **3+ badge
types** · **badge book entry** · **offline**.

## Fix

A **Badge Book** screen + home entry (🏅) with **4 lifetime badges**, each
derivable from existing local state — fully offline, no new tracking clockwork:

| Badge | Emoji | Condition |
|---|---|---|
| 10 Rounds Hero | 🎮 | ≥ 10 completed sessions |
| Star Collector | ⭐ | ≥ 50 stars |
| 7-Day Streak | 🔥 | ≥ 7-day streak |
| Land Champion | 👑 | a whole land fully mastered |

- **Store** (`store.ts`) — `NovaState.badges: string[]` (persisted earned set);
  `novaSyncBadges(kidId, earned) → string[]` merges the currently-earned ids
  and returns the NEWLY-earned subset (so the UI celebrates each exactly once).
  The conditions live in App.tsx (they read the skill catalog); the store only
  persists the union.
- **Config** (`App.tsx`) — `BADGES` array: id/emoji/name/nameBn/hint/hintBn +
  `earned(ctx)`. Names are locale-packed like Nova outfits — a new country
  adds its language field, no rewrite (#131).
- **Celebration** — a `useEffect` on home watches the earned-id signature and,
  for each new badge, `tada()` + a spoken cheer in the app's language.
- **Badge book screen** — `screen === "badges"` renders a grid: earned badges
  glow (🏅, pulse), locked ones are dimmed with 🔒 + a gentle "keep playing"
  hint. Tapping a badge speaks its name.
- **Home** — a 🏅 quick-icon between Cards and the Castle.
- **i18n** — 7 `Strings` entries EN + BN (`badgeTile/Title/Sub/Earned/Locked/
  NewSpeak`), Bangla digits via `bnNum`.
- **CSS** — `.badge-grid/.badge-card` (earned/locked states) in styles.css.

## Files
- `apps/kid/src/store.ts` — `NovaState.badges`, `novaSyncBadges`
- `apps/kid/src/App.tsx` — `BADGES` config + `fullyMasteredWorlds()`, Strings

- `apps/kid/src/styles.css` — badge book styles
