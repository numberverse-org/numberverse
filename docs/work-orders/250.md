## What shipped

Accessibility toggles (large type, high contrast) across BOTH areas — one
genuinely global toggle.

### Global toggle (the contract)
- The parent portal and the kid app are **same-origin** (`kids.munna-khan.xyz`
  and `…/parent/`), so both read/write **one** localStorage key: `nv_a11y`.
- Toggling big text in the kid app applies to the parent portal the next time
  it opens (and vice-versa). A `storage` listener live-syncs open tabs.

### Shared shape (`packages/core`)
- **`a11y.ts`** (pure, no DOM) — `A11yPrefs { bigText, highContrast }`,
  `parseA11yPrefs` (never throws on a tampered key), `a11yToStorage`,
  `a11yStorageKey`. Both apps import the exact same contract.

### Kid app (`apps/kid`)
- **`game/a11y.ts`** — `readA11y`/`writeA11y`/`applyA11y`/`initA11y`; applies
  `.nv-big-text` / `.nv-high-contrast` classes on `<html>`.
- **Settings UI** — two switches (🔍 Big text, 🎨 High contrast) next to the
  projector toggle, with EN + বাংলা labels + screen-reader announcements.

### Parent portal (`apps/parent`)
- **Topbar toggles** — two compact toggle chips (🔍 / 🎨) that share the same
  `nv_a11y` key; EN + বাংলা labels via the `A11Y_LANGS` country-pack map.
- Applies the same `<html>` classes; storage listener keeps the portal in sync
  with the kid app.

### CSS
- `html.nv-big-text { zoom: 1.2 }` — the apps' type is px-based, so `zoom` is
  the honest way to scale EVERY screen. High contrast = stronger borders,
  brighter text, prominent focus rings.

## i18n
- Every new string is EN + BN. `A11Y_LANGS` + the kid's a11y strings are config
  maps (the #131 country-pack seam) — a new locale = new keys, no rewrites.
