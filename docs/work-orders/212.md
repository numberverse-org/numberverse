# Work Order 212 — Social: professions & their tools

**Issue:** #212
**Status:** DONE (PR #539)

## Problem
A band-2 social game matching Bangladeshi helpers to their tools (ডাক্তার →
স্টেথোস্কোপ). Kids see helpers every day but don't always connect the person
to what they use.

## Fix
New `ProfessionsMatchScene` — picture-match 12 community helpers to their tools:
- **12 professions:** doctor 👨‍⚕️→🩺, teacher 👩‍🏫→📚, farmer 👨‍🌾→🌾, fisherman
  🧑‍🎣→🐟, police 👮→🚨, firefighter 👨‍🚒→🧯, builder 👷→🔨, chef 👨‍🍳→🍳, tailor
  🧵→✂️, barber 💇→💈, postman 🚴→✉️, artist 🎨→🖌️ — every one from everyday
  Bangladeshi life.
- **Picture match:** the helper's emoji + name shows big (Bangla in bn
  locale); the kid taps the matching tool from a 2×2 grid of tool emoji cards
  (emoji + name). Correct → card pops green + speaks the tool name; wrong →
  shakes red and re-asks.
- **All 12 shown:** a shuffle-bag guarantees every 12 matches present all 12
  helpers exactly once — no kid leaves before meeting the whole community.
- **Bangla+EN:** helper and tool names are localized (ডাক্তার/doctor,
  স্টেথোস্কোপ/stethoscope).
- Each round = K quick matches (3/3/4/4/5/5 by level).

Wired as skill `bgs-professions` (band 2 BGS, c2-bgs-2, class 2), game
`game-professions`, scene key `ProfessionsMatch`, bg "floral". i18n: 28 new
pf* keys (12 helpers + 12 tools + 4 game, EN + BN).
