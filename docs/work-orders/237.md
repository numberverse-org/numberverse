# Work Order #237 — Parent: per-kid reading & story progress view

**Status:** DONE · **PR:** #553 · **Branch:** feat/237-reading-story-progress · **Merge:** main

## Problem
Parent portal has a generic mastery table but no focused view of which
read-aloud stories/books each kid finished and their retell quiz scores.

## Fix
New "📚 Reading & stories" card on the parent dashboard (right after This week).

- **Per-kid story list** — the 4 read-aloud/story skills across EN+BN tracks:
  Read a story (গল্প পড়ি), Story comprehension (ছোট গল্প পড়ি), Story
  sequencing (গল্প সাজানো), Read & answer (পড়ে উত্তর দাও). Each row shows
  EN + Bangla titles.
- **Completion + score** — mastery progress bar + %, correct/attempts score,
  and a status chip (🌱 Not started / 🔶 In progress / ✅ Finished).
- **Offline-friendly** — reads the `mastery` state already loaded with the
  dashboard; zero new network calls, works even when the API is unreachable.
- Card derives the story list from the `@numberverse/core` SKILLS catalog by
  game id, so new story games appear automatically.
