# #217 — Bangla: simple idioms for kids

**Status:** DONE · **PR:** #544 · **Branch:** feat/217-idioms

## Problem
A band-3 vocabulary game matching simple Bangla idioms to kid-friendly
meanings. Requirement: "12+ idioms · Picture hints · Spoken examples · i18n clean."

## Fix
New `IdiomsScene` ("Bangla idioms", skill `bn-idioms`, c3-bangla-7, class 3):
- **12 kid-friendly idioms** (বাগধারা): তালগাছে কুমড়ো, চোখে আঙুল দিয়ে দেখা,
  দুধে-ভাতে থাকা, গায়ে ফুঁ দিয়ে বেড়ানো, আকাশ-পাতাল, টু শব্দ নেই, মাথা খাটানো,
  কান খাড়া করা, হাত খালি, মুখ ভার করা, পেটের কথা, সোনায় সোহাগা.
- **Picture hints**: each idiom shows with an emoji illustration (🌴🎃, 👁️,
  🥛🍚…) inside a white card + the Bangla phrase.
- **Spoken examples**: the idiom is spoken aloud on show; a 🔊 replay button
  speaks a kid-friendly example sentence in the app language.
- **Game**: three meaning buttons (one correct + two distractors from other
  idioms, always 3 distinct). Correct → pop + win + green flash; wrong → gentle
  shake + "try again" (soft feedback, no penalty).
- **Shuffle-bag** over all 12 guarantees full coverage; round-level dedupe
  prevents a bag-refill from repeating an idiom within a round.
- **Level ladder** [4,4,6,6,8,8] = idioms per round.
