# #138 — Kid dictation: record own voice + replay (on-device only)

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Kids want to say their answer out loud and hear themselves back — an oral
"check my work" loop. Needs to be parent-gated and strictly on-device (privacy
contract: no upload, no persistence, no server round-trip).

## Fix

Full-stack, locale-aware (`STR[lang]` EN + BN in App.tsx):

- **API** — `KidSettings.voice_record_enabled` column (default off),
  schemas `KidSettingsIn/Out`, router write.
- **Parent portal** — `🎙️ Voice recording` toggle chip + privacy note
  ("Recordings stay on this device and are never sent to the server").
- **Kid app** — `src/game/voiceRecorder.ts` (MediaRecorder, object URL,
  revoked on stop, mic only inside an explicit tap), settings-screen dictation
  row (record / stop / replay / delete), pulsing-recording style, `useCallback`
  hook. Dictation row is hidden unless the parent flips the toggle.
- **Strings** — 7 new keys (`settingsDictate*`) added to the EN + BN dicts;
  the audit's per-locale parity check covers them.

Privacy contract: recordings live only as a blob URL in the current tab;
`URL.revokeObjectURL` on stop, no network, no storage. Tested on the
operator's own devices only.
