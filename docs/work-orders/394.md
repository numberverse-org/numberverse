# Work order #394 — Natural Bangla world/level names + syllabus FAB
> milestone: bangla-ux-wave · branch: `feat/issue-394`

## Acceptance criteria (from the issue)
- [x] No English word transliterated phonetically into Bangla (world names, titles)
- [x] Bangla reads natural/colloquial — not literary (বপন/নির্মাণ/গণনা style avoided)
- [x] Syllabus FAB appears only when `hasParentSession()`, navigates on tap
- [x] core rebuilt; tsc, i18n audit, build all green

## Goal
Bangla UI read like stiff transliteration / formal literary text (স্প্রাউট গ্রোভ,
গণনা ও পপ, বপন ও গণনা, রকেট নির্মাণ, স্থানীয় মান টাওয়ার …). Kids deserve the
words people actually say. Plus: a signed-in parent who just cleared the gate gets
one thumb-tap straight into learning — no scrolling the whole syllabus again.

## What shipped

- `packages/core/src/skills.ts` `BANDS[].titleBn` → real Bangla words:
  কুঁড়ির বাগান · মাঠের কুটির · নদীর শহর · আকাশের দুর্গ · তারার পাঠশালা
