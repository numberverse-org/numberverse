# #216 — Bangla: ordinal words (প্রথম-দ্বিতীয়-তৃতীয়)

**Status:** DONE · **PR:** #543 · **Branch:** feat/216-ordinals

## Problem
A band-2 game ordering objects with ordinal Bangla words. Requirement:
"1st-10th ordinals · Race-line visuals · i18n clean."

## Fix
New `OrdinalsScene` ("Race positions", skill `bn-ordinals`, c2-bangla-12, class 2):
- **Race-line visuals**: N runners (cute animals 🐰🐢🐹🐸🦊🐻🐼🦄🐶🐱) line up
  in their finishing order with a checkered finish flag 🏁 on the right — the
  winner touches the flag. Each runner idles with a gentle staggered bob.
- **1st-10th ordinals**: a spoken + written ordinal word ("দ্বিতীয়" / "second")
  asks *"Who is …?"* and the kid taps the runner in that position — counting
  from the finish line. Wrong taps flash red + gently pulse the flag to show
  where counting starts (no penalty, soft feedback).
- Correct tap → green flash + pop + ⭐ star burst + "Yes! {ord}!" spoken.
- **Level ladder** [3,4,5,6,8,10] = runners in the race; each round asks EVERY
  position 1..N exactly once (shuffled), so all ordinals present are covered —
  all ten ordinals appear at level 6.
- Ordinal words in the app language: Bangla (প্রথম…দশম) or English (first…tenth).
