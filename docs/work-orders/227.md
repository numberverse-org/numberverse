# #227 — Number bonds to 10 & 20

**Status:** ✅ done

## Problem
Band-2 (ages 4–6) already had bonds to 10; the roadmap asked for a bonds-to-20
ladder too, with a ten-frame visual aid, instant feedback, and i18n clean.

## Fix
One shared `NumberBondsScene` now backs BOTH ladders (#227) — the App passes
the skill id (`number-bonds-20` vs `number-bonds-10`), and the scene switches
target (20 vs 10), ladder, framing seed, header title, and ten-frame together.

- **Ten-frame aid** — the number renders as ten-frame cells: filled (blue) =
  the shown part; empty (yellow-outline) cells = the missing addend, which IS
  the answer. Bonds to 10 → one ten-frame; bonds to 20 → a double ten-frame.
- **New skill + game** — `number-bonds-20` (band 2 math, 2.OA.2) with
  `game-bnbonds20` ladder `[10,12,14,16,18,20]`, mapped to the SAME NumberBonds
  scene (the shared-scene pattern from CountPop).
- **Answer range generalizes** — the option spawner now allows up to `target-1`
  (19 for bonds to 20), keeping 4 unique options + the correct one.
- **i18n** — `titleNumberBonds20` EN/BN, buttons + hint digits localized with
  Bangla digits in bn mode, inline hint already bilingual (uses the live target).
- Added to audit SCOPE_CAP (`number-bonds-20: 20`) and seed.py parity.
