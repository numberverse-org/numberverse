# Work Order — #170: Bangla coin values (টাকার চেনা)

**Status:** ✅ Merged via PR #497

## Problem
bd-taka (band 2) covers ৳1/2/5 combo-sums and change for class 1. #170 adds
the ৳10 note, spoken Bangla money names (এক টাকা…), and a distinct
count-to-total mechanic — value recognition + counting to a total.

## Fix
New `CoinValueScene` (`apps/kid/src/game/CoinValueScene.ts`), band 2 math,
scene key `CoinValue`, skill `bn-coin-values` (c2-math-5), game
`game-coinvalues` (difficultyLevels `[8,8,12,12,20,20]` = count-mode total cap).

**Two alternating games (done-when):**
1. **VALUE RECOGNITION** — a coin (Bangla numeral printed: ৳৫) or the ৳10 note
   (green rect) is drawn; the kid taps its Western value (৳5) among the 4
   denoms. Bangla name spoken up front + on correct.
2. **COUNT-TO-TOTAL** — a ৳ total (Bangla digits: ৳৮) is shown; the kid taps
   coins/notes into a centered tray. Sum < total → keep going, == → win +
   speaks the total (৳৮), > → tray shakes and clears gently. Always solvable
   (৳1s reach any total). Total cap grows 8 → 12 → 20 by level.

**Rendering:** gold discs sized by denomination (৳১ smallest → ৳৫ largest),
green rounded-rect for the ৳10 note — real "count the coins" visuals.
