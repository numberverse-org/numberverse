# #232 — Animal food chains

**Status:** ✅ done

## Problem
Band-2 (ages 4–6, science) needed a game ordering simple food chains
(grass → deer → tiger) with an arrow ordering mechanic, i18n clean.

## Fix
New Phaser scene `FoodChainScene` (`apps/kid/src/game/FoodChainScene.ts`):

- **6 chains** — grass→grasshopper→frog, grass→rabbit→fox,
  grass→mouse→snake, grass→deer→tiger, seaweed→fish→shark, flower→bee→bird.
  Every chain is producer → plant-eater → meat-eater, easy → tricky.
- **Arrow ordering** — the producer is pre-placed; the kid taps who EATS it
  from three shuffled cards. Correct → the card flies into the next slot and
  the "→" arrow lights up between the links. Three taps build the whole chain.
- **Difficulty ramp** — the chain pool grows with level (3 → 4 → 6).
- **i18n clean** — localized header, "Who eats the grass?" question + speech,
  and inline EN/BN organism words; emoji labels are language-neutral.
