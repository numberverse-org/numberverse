# Work order #322 — Kotha: story inspector in parent panel
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-322`

## Goal
Browse a kid's learning stories (what was tried, how Moni diagnosed it, what we did) in the parent panel.

## Done when
- [x] Story list + filter
- [x] Per-kid view
- [x] Reads learning_stories
- [x] Offline-friendly

## What shipped
- **Story list + filter** (`apps/kid/src/App.tsx` — new `StoryInspector`
  component): a parent-panel card listing the active kid's learning stories,
  newest first. Outcome chips (All / Wrong / Correct) and Moni error-kind chips
  (misconception / gap / fatigue / guessing / slip) filter live. Each row shows
  ✓/✗ outcome, skill title (+ BN), the error kind, the misconception label, the
  Moni action taken, Moni's reason line from the context envelope, and a
  friendly "2h ago" timestamp. Capped at 50 rows for perf.
- **Per-kid view** — the inspector reads `kothaStories.filter(kidId === activeKid.id)`, so it always reflects the kid currently selected in the parent panel.
- **Reads learning_stories** — it reads the LOCAL Kotha story log (the same
  `KothaStory[]` that the durable outbox syncs to the server's
  `learning_stories` table), so the parent sees exactly what Moni recorded.
- **Offline-friendly** — pure Zustand store, no network; works with zero
  connectivity and no server round-trip. Fully localized EN + BN
  (`kothaInspector*`, `kothaKind*`, `kothaAgo`, ...).
