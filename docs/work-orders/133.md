# #133 — Screen-reader deep support (VoiceOver/TalkBack)

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Canvas + React app: screen readers can't read Phaser pixels; round feedback
and toggle state were only visual.

## Fix

- **`#sr-live` live region** (`aria-live="polite"`, visually hidden) in the
  home/app root — every round result, mastery crossing and music toggle is
  announced in the app's language via `announce()` (new `a11y*` STR keys,
  EN + BN).
- **Critical-path labels**: home Play button `aria-label`, plus confirmed
  existing labels (journey path, kid picker, switches `role="switch"` +
  `aria-checked`, back/icon buttons).
- **Walkthrough doc** `docs/A11Y_SCREENREADER.md` (acceptance criterion 1) —
  documents the pattern, the announce table, labeled paths, honest scope
  (scenes stay canvas; live region is the bridge), and the test path.

## Files
- `apps/kid/src/App.tsx`, `apps/kid/src/styles.css` (`.sr-only`)
- `docs/A11Y_SCREENREADER.md` (new)
