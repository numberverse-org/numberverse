# #134 — Per-land ambient music + SFX pack

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

One chiptune loop for every land — Sprout Grove sounded like Star Academy.

## Fix — zero-asset, land-rooted music (fits offline + i18n-any-country)

All synthesized in WebAudio (no asset files — offline-friendly, tiny bundle).

- **`audio.ts`** — 5 land themes (`LAND_THEMES` keyed by band 1–5): each has
  its own pentatonic melody pair, bass line, tempo (`stepDuration` 0.42 →
  0.19s) and volume:
  - 1 Sprout Grove: slow gentle lullaby (G-rooted)
  - 2 Cottage Fields: bouncy C-major hop
  - 3 River Town: flowing stream arpeggio
  - 4 Sky Castle: airy high shimmer
  - 5 Star Academy: confident upbeat
- **`setMusicTheme(bandId)`** swaps theme + the land's celebratory key so the
  `win()` fanfare roots "of this land" (SFX pack). Scheduler stays monotonic —
  the next scheduled step picks up the new theme, no bursts.
- **`App.tsx`** — theme follows play: set in `startSingleSkill(skill.band)`,
  `startPlayWorld(b.id)`, and an effect on the home screen (current journey
  stop's band).
