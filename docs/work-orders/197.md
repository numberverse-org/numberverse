# Work Order 197 — Math: mixed numbers & improper fractions intro

**Issue:** #197
**Status:** DONE (PR #524)

## Problem
Band 3 kids meet mixed numbers (1½) and improper fractions (3/2) as two names for
one quantity. They need to SEE the equivalence — on bars and on a number line —
before doing any arithmetic.

## Fix
New `MixedFracScene` — convert-visually game:
- **Bar + number line:** every question draws the given form as a bar model with a
  0..3 number line underneath marking the exact value.
  - Mixed form = whole bars + a fraction bar (1 whole + 1 half bar).
  - Improper form = unit bars split into halves/ thirds/ quarters with the first
    n segments filled (3 halves).
- **Both conversion directions alternate:** "What is 1 1/2 as an improper
  fraction?" → tap 3/2. Then "What is 3/2 as a mixed number?" → tap 1 1/2.
- **4 answer cards** (2×2); distractors are other valid fractions that never share
  the answer's VALUE (6/4 never appears next to 3/2 — it's also equal to 1½).
- Correct → "1 1/2 = 3/2" floats + is spoken (mfSpeak).

Fractions: denominators 2–3 (lvl 1–4), 2–4 (lvl 5+); whole part 1–2 so values sit
between 1 and 3 on the line. [2] alone can't fill 4 options (only 3/2 and 5/2
exist), so the smallest pool is [2, 3] — min 5 value-distinct candidates.

Wired as skill `en-mixedfrac` (band 3 math, c3-math-9, class 3), game
`game-mixedfrac`, scene key `MixedFrac`, bg "candy". i18n: 6 new mf* keys (EN + BN).
Bangla digits for the BN locale.
