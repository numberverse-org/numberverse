# #20 — New lands: Jungle + Polar themes

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

The journey was a single linear world (BANDS 1–5). Issue's acceptance: **two
more lands past the existing five** — a Jungle canopy and a Polar peaks —
each with its own palette, music, map icon, and **nine new skills** that
belong in those worlds.

## Fix

Everything is **data-driven, locale-extensible** (#131): a land is a config
entry (BAND + palette + emoji + SVG + music theme), a skill is a data entry
(core + seed), and every reused game scene reads `step.mode` / `step.skill`
so no new Phaser scene was required for the new content.

**Worlds** (`packages/core/src/skills.ts` + `App.tsx` + `svgs.ts` + `audio.ts`):
- `BAND 6 · Jungle Canopy` (`জঙ্গলের চাঁদোয়া`, ages 11–14): palette
  `#1e4d1f/#43d17c/#c8f7a9`, deco `🌴 🦜 🌿`, palm SVG map icon, WebAudio
  theme `jungle-canopy`, landRoot 587.33 Hz.
- `BAND 7 · Polar Peaks` (`মেরু শৃঙ্গ`, ages 12–15): palette
  `#1f3a5f/#8fd3ff/#e3f4ff`, deco `❄️ 🐧 🏔️`, peaks SVG map icon, theme
  `polar-peaks`, landRoot 1046.5 Hz.

**Nine new skills** (core + `apps/api/app/seed.py` in sync — 58 total):
- Band 6 (Jungle): `mult-fluency-6-9` (game-multable), `divide-within-100`
  (game-division), `fraction-read` (game-pizzafrac), `clock-minute`
  (game-clock), `bn-conjuncts` (game-bnmatras).
- Band 7 (Polar): `decimals-tenths` (game-decimals), `percent-of-number`
  (game-percent), `fraction-simplify` (game-fracmatch), `bgs-heritage`
  (game-bgs).

**Two content modes added** to existing scenes (no new scenes):
- `BnMatrasScene` — new `conjuncts` mode (`bn-conjuncts`): 14 Bangla conjuncts
  (ক্ষ জ্ঞ ঙ্ক ণ্ড …) reuse the same 2→1 combine mechanic; EN/BN titles +
  prompt keys (`titleBnConjunct`, `tapConjunct`).
- `BgsFactsScene` — new `heritage` mode (`bgs-heritage`): 10 festival/craft/
  food/landmark facts (পহেলা বৈশাখ, পিঠা, ঢাকাই মসলিন, নকশী কাঁথা, বাগেরহাট,
  সোমপুর, নবান্ন …) drawn from a `kind: "heritage"` pool.

**Plumbing** (`App.tsx`): `SessionStep["mode"]` now includes `"conjuncts"`;
`modeForSkill()` maps `bn-conjuncts → "conjuncts"`; every `scene.start`
already passes `skill: step.skillId` so reused scenes track the right mastery
keys. World unlock flows through the existing `worldUnlocked()` (beat previous
band) with no new logic.
