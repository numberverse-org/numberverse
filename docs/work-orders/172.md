# Work Order — #172: Bangla direction words (উপরে-নিচে-ডানে-বামে)

**Status:** ✅ Merged via PR #499

## Problem
Band 1 needed a spatial-language skill: following spoken direction words to
physically move an object — the basis of map-reading and instruction-following.

## Fix
New `DirectionWordsScene` (`apps/kid/src/game/DirectionWordsScene.ts`), band 1,
scene key `DirectionWords`, skill `bn-direction-words` (c1-bangla-7), game
`game-directionwords` (difficultyLevels `[3,3,4,4,5,5]` = path steps).

**Mechanic — grid + spoken instruction (done-when):**
- A 🐱 sits on a 4x4 grid; a ⭐ goal is marked. A SPOKEN instruction tells which
  way to go ("উপরে যাও") and shows the word big with its arrow (↑ উপরে).
- Four direction buttons (উপরে/নিচে/বামে/ডানে, arrows + labels) in a 2×2 layout.
  Tapping the matching button hops the character one cell; wrong taps shake,
  re-speak the word, and retire that button (narrow to the right one).
- Follow the whole random path to the goal → win. Path length grows 3 → 5 by
  level. Directions: all 4 (উপরে ↑, নিচে ↓, বামে ←, ডানে →).

**Path generation:** random walk, never immediately backtracking (no
"up-then-down" nonsense), always in-bounds on the 4×4, every step resolves to
exactly one direction word.
