# Work Order — #182: English story sequencing (first then last)

**Status:** ✅ Merged via PR #___

## Problem
Band 2 reading needed the comprehension skill of putting events in order —
"first, then, last". A row of scrambled picture cards is the most natural way
to make sequencing visible and hands-on.

## Fix
New `StoryScene` (`apps/kid/src/game/StoryScene.ts`), band 2, scene key
`Story`, skill `en-story` (c2-english-8), game `game-story` (difficultyLevels
`[3,3,4,4,4,4]` — 3 cards early, 4 cards later).

**Mechanic — drag to reorder (done-when):**
- **16 mini-stories (done-when, ≥10):** 8 three-frame + 8 four-frame (seed→rain→
  flower, egg→chick, caterpillar→butterfly, plant→water→sun→rice, letter→mail→
  friend reads, day→night→morning …). Each frame is an emoji + short caption.
- Cards sit in a row with ১ ২ ৩ step badges (local digits). The kid DRAGS a
  card horizontally; on release it swaps with the nearest slot (Back.easeOut
  snap). Correct order → 🎉 + the whole story is spoken aloud ("First a seed,
  then rain falls, and last a flower grows.").
- The row is shuffled until it is NOT already correct — every round needs a real
  move. Dragging is locked the moment the story is solved.
