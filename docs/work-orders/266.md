# #266 — Privacy: PII scrubber for logs

**Status:** in progress (2026-08-13)

## Problem

The API logs with Python's stdlib `logging` (`log.info/warning` in main.py,
embeddings.py, seed.py, migrations.py). Nothing guaranteed that a PII-shaped
value (email, phone, IP, MAC, device id) couldn't be interpolated into a log
line — e.g. an exception string or a request payload echoing user data.

## Fix

New `apps/api/app/scrub.py` — a dependency-free PII redactor:

- `redact_text()` — replaces emails, IPv4/IPv6, BD phone numbers (mobile +
  landline formats), 16-19 digit card-like runs, ≥12 digit runs (device ids)
  and MACs with `[REDACTED]`. Idempotent.
- `ScrubFilter` (logging.Filter) — attached to every root-logger handler in
  main.py, so **every** log record's message + args are redacted before write.
- `redact_context()` — deep-walk a story context envelope (dicts/lists/str
  leaves only; non-str leaves preserved; caller's dict never mutated).

## Files
- `apps/api/app/scrub.py` — new redactor + filter
- `apps/api/app/main.py` — install `ScrubFilter` on all handlers
- `apps/api/tests/test_scrub.py` — new self-contained unit tests
