# Work Order — #178: English contractions (I'm, don't, can't)

**Status:** ✅ Merged via PR #___

## Problem
Band 3 grammar needed contractions — the short forms (I'm, don't, can't) that
kids meet constantly in reading and writing but never consciously map to their
two-word origins.

## Fix
New `ContractsScene` (`apps/kid/src/game/ContractsScene.ts`), band 3, scene key
`Contracts`, skill `en-contractions` (c3-english-4), game `game-contracts`
(difficultyLevels `[3,3,3,4,4,4]` = option count).

**Mechanic — match + read aloud (done-when):**
- **24 contractions** (I'm→I am, don't→do not, can't→cannot, won't, isn't,
  aren't, wasn't, weren't, haven't, hasn't, hadn't, didn't, doesn't, couldn't,
  wouldn't, shouldn't, I'll, we'll, they'll, I've, we've, let's, that's, it's).
- Rounds alternate ~50/50: contraction shown → tap its full form, and full form
  shown → tap its contraction. The target is spoken aloud (🔊 replay); a correct
  match RE-READS the whole pair aloud — "can't … cannot" — so the contraction
  and its words are always heard together.
- Wrong taps retire that card and re-speak the target. Option count 3→4 across
  6 tiers.
