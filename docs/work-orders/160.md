# Work Order #160 — Bangla: sentence builder (বাক্য সাজাই)

**Status:** ✅ Merged via PR #487

## Problem
Band-2 readers (ages 4–6) know isolated words but not how to order them into a
sentence. Bengali is Subject–Verb–Object, and kids need a concrete, playful way
to feel that order. The existing `game-bnsentence` is band-5 (tap whole
sentences in order) — nothing teaches early SVO grammar with word tiles.

## Fix
New `SentenceBuilderScene` (key `SentenceBuilder`, skill `bn-sentence-builder`,
game `game-sentencebuilder`, band 2):

- **12 simple SVO sentence patterns** (≥ 10 required): আমি ভাত খাই, বাবা মাছ
  কিনলেন, মেয়েটি গান গায় … each a subject + verb + object a band-2 reader
  knows.
- **Role-colored tiles:** subject = orange, verb = teal, object = green
  (`btnFromColor` green). Distractors are GREY — colour teaches the role.
- **Tap-to-snap in SVO order:** tiles fill the next empty slot left→right.
  Tapping the right-role tile snaps it in (tween + warm `speak(word,{lang:"bn"})`).
  Tapping a grey distractor retires it (`hintWrong` kill). Tapping a colored
  tile out of order is coached with a role-specific bilingual hint
  (`keepOnWrong` — the tile stays alive, never a harsh fail).
- **Full sentence read aloud** when the 3 slots fill: `speak("আমি খাই ভাত")`.
- **Difficulty ladder** `[1,1,2,2,2,2]` (distractor count), and levels 3+ drop
  the slot color-scaffold (`SLOTS_COLORED`) so order comes purely from grammar.
- 3 sentences per round, 3 rounds per level.
