# Work order #11 — Count to 100 + place value (tens/ones)

**Issue:** #11 · **Branch:** feat/issue-11 · **Priority:** high (kid-first)

## The missing milestone
Count-to-50 stops at 50; NCTB class-2 requires counting to 100 with an
understanding of tens and ones. This adds the bridge: build a target number
(up to 100) by assembling **place-value rods** — tapping +1 ones that
**auto-bundle into a ten-rod** at 10, and +10 rods at higher levels.

## Acceptance (from issue)
- New skill `count-to-100` (band 2) + game: tap/assemble bundles of 10 (place-value rods).
- Game + scene + seed + i18n EN/BN, audit clean.

## Implementation checklist (5-spot)
1. **core** `packages/core/src/skills.ts`: skill `count-to-100` (band 2, class 1,
   NCTB c1-math-1, game `game-count100`) + `GAMES` entry (6 difficulty tiers)
   + `GAME_SCENES['game-count100'] = 'Count100'`.
2. **scene** `apps/kid/src/game/Count100Scene.ts`: build-to-target rod game.
   - Question panel "Make {n}" / instruction at bottom.
   - "+1" button adds a unit cube; 10 ones **bundle** into a ten-rod (chime + speak).
   - "+10" rod button shown only when target ≥ 40 (early levels FORCE the bundle lesson).
   - Both buttons disable when they'd overshoot the target.
   - Tens rods + ones cubes rendered with Graphics (no new assets).
   - Progress bar fills total/target; big readout `T tens + O ones = n`.
   - Correct → `win()` + celebrate + `onRoundDone(true, ms, n)` → next round.
   - Mobile-first Scale.RESIZE re-layout, `nv:noSwipe` (no swipe target).
3. **engine** `apps/kid/src/game/engine.ts`: import + register `Count100Scene` in the scene array.
4. **seed** `apps/api/app/seed.py`: `("count-to-100", 2, "math", "Count to 100", "১০০ পর্যন্ত গুনি")`.
5. **i18n** `apps/kid/src/game/i18n.ts`: EN + BN for title, make/round, tens/ones,
   breakdown, bundle-celebration keys (audit ① requires every used t() in both).
