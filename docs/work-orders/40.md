# Work order #40 — Bangla: three-digit numbers 100–1000 (place value to hundreds)
> milestone: v18 — content wave 2 · branch: `feat/issue-40`

## Acceptance criteria (from the issue)

## Goal
A band-2/3 Bangla math game teaching three-digit numbers with hundreds/tens/ones
place value (শতক পর্যন্ত, হাজার নয়).

## Done when
- [x] Kid builds a target number 100–999 with 100/10/1 blocks
- [x] Tens/ones idea extends to hundreds
- [x] Spoken in Bangla (শতক/দশক/একক)
- [x] EN + BN translations, i18n audit clean

## What shipped
- **New skill `count-to-999` (band 2, "Build to 999" / "৯৯৯ পর্যন্ত গঠন")** + game
  `game-build999` + scene `Build999Scene`, slotted right after count-to-100 in the
  brain ladder (numbers → build → then calculate).
- **Build-to-999 mechanic** — the count-to-100 "bundle & count" loop extended to
  hundreds: +1 (ones) / +10 (ten-rods) / +100 (hundred-flats); 10 ones → one
  ten-rod, 10 rods → one hundred-flat, each with a chime + toast.
- **Base-10 blocks** — 10×10 hundred-flats (indigo), ten-rods (blue), one-cubes
  (gold), all drawn from the running count with a H+T+O = N breakdown line.
- **Spoken in Bangla** — every add reads the running total aloud via bnNumber;
  the done-line speaks the target too.
- **Scope guard** — `count-to-999: 999` added to audit SCOPE_CAP.
- i18n keys `titleBuild999` + `build999*` in EN + BN; audit clean (49 skills /
  46 games / 46 scenes).
