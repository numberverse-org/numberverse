# Work Order 207 — Science: light & shadows (predict where the shadow falls)

**Issue:** #207
**Status:** DONE (PR #534)

## Problem
"Shadow goes the opposite way from the light" is a rule kids can only learn by
watching it move. A predict-then-check game makes them state the rule first
(predict) and see it confirmed (check) — the classic science-loop.

## Fix
New `ShadowGuessScene` — predict where the shadow falls as the light moves:
- **Source moves → shadow changes:** the light sits at one of 4 places — far
  low-left 🌅, high left ☀️, high right ☀️, far low-right 🌇 — and the object
  (tree 🌳 / teddy 🧸 / castle 🏰 / tent ⛺) stands in the middle. Moving the
  light moves the shadow: opposite side always, LOW light → long FAR shadow,
  HIGH light → short NEAR shadow.
- **Predict-then-check:** 4 shadow spots (dashed ellipses) sit on the ground;
  the kid taps where the shadow will fall. A green ring + pop confirms, or a
  red shake teaches, then the REAL shadow grows in at the correct spot with a
  faint light beam from source → shadow (straight-line travel).
- **Speaks** the rule: "The shadow is opposite the light" / "ছায়া আলোর বিপরীতে
  পড়ে" (lshSpeak), hint "The shadow goes away from the light".
- **Lvl 1–2** use only the two high lights (near shadows), lvl 3+ all four.

Wired as skill `en-light-shadows` (band 2 science, c2-science-8, class 2),
game `game-shadows`, scene key `ShadowGuess`, bg "sky". i18n: 6 new lsh* keys
(EN + BN).
