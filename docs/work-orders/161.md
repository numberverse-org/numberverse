# Work Order #161 — Bangla: short-paragraph comprehension (ছোট গল্প)

**Status:** ✅ Merged via PR #488

## Problem
Band-3 readers (ages 6–8) can decode words but need to extract meaning — who
does what, where, when. There was no early comprehension game in the kid app:
`game-bnsentence` is sentence *building*, not story understanding.

## Fix
New `StoryReadScene` (key `StoryRead`, skill `bn-story-read`,
game `game-storyread`, band 3):

- **12 graded mini-stories** (≥ 10 required): 2–3 Bangla sentences each, all
  with everyday vocabulary. The first 4 (2-sentence, simplest) form the easy
  pool for levels 0–2; levels 3–5 draw from all 12.
- **Who/what/where/when questions** answered with **PICTURE (emoji) options** —
  the skill is comprehension, not decoding.
- **Read-aloud toggle (🔊)** re-reads the story + question anytime, and every
  story auto-reads aloud in warm Bangla on show.
- **Difficulty ladder** `[3,3,3,4,4,4]` = answer-option count (3 → 4 options).
- Wrong taps retired gently via `hintWrong` (bilingual hint); correct taps fire
  combo fireworks. 3 stories per round, 3 rounds per level.
