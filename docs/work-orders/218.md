# #218 — Bangla: verb-form gender agreement

**Status:** DONE · **PR:** #545 · **Branch:** feat/218-verbgender

## Problem
A band-3 grammar game choosing the right verb form for masculine/feminine
subjects. Requirement: "10+ sentence slots · Picture context · i18n clean."

## Fix
New `VerbGenderScene` ("Verb match", skill `bn-verbgender`, c3-bangla-8,
class 3):
- **12 sentence slots** pairing pictured subjects with agreeing verbs:
  ছেলেটি খেলছে 👦⚽, মেয়েটি নাচছে 👧💃, ভাই পড়ছে 👨📚, বোন গাইছে 👩🎤,
  রাজা যান 👑, রানী আসেন 👸, কৃষক চাষ করেন 👨🌾, মা রান্না করেন 👩🍳,
  ডাক্তার রোগী দেখেন 🧑⚕️, নার্স সেবা করেন 👩⚕️, দাদা বসেছেন 👴, দিদি খেয়েছেন 👵.
- **Picture context**: each slot shows the character + action emoji, with the
  subject + a verb blank ("ছেলেটি ______") below.
- **Game**: three verb buttons — one correct form + two wrong person/honorific
  forms (distinct). Correct → pop + win + the full sentence is spoken
  ("ছেলেটি খেলছে"); wrong → gentle shake + "try again" (no penalty).
- **Shuffle-bag** over all 12 slots + round-level dedupe (from #217) guarantee
  every slot is met, never twice in one round.
- **Level ladder** [4,4,6,6,8,8] = slots per round.
