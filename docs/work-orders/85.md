# #85 — Parent: offline sync indicator + manual sync

## What
Topbar **sync chip** + **manual sync button**:
- 🟢/🔴 live online/offline dot (from browser network events).
- "synced 2m ago" — tracks the last successful dashboard data load (`lastSync`,
  set by `refreshAll` on every successful fetch).
- "↻ Sync now" re-runs the full per-kid data load against the app's own API.
- EN + BN (`SYNC_LANGS`, same country-pack seam). Zero analytics — talks only
  to the app's API, nothing else.

## Reuse
The `lastSync` timestamp is shared with the #7 diagnostics card (set once in
`refreshAll`), so both stay consistent.

- `apps/parent/app/page.tsx` — `SYNC_LANGS`, online tracking, `manualSync`,
  `relTime()`, topbar chip UI
- `apps/parent/app/globals.css` — `.sync-chip`, `.sync-dot`, `.sync-btn`
