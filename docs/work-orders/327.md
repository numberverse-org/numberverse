# Work order #327 — Moni: fatigue-aware session pacing
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-327`

## Goal
Auto-pace sessions with gentle break prompts when Moni detects late-session fatigue.

## Done when
- [x] Fatigue threshold respected
- [x] Break screen
- [x] Never blocks forever

## What shipped
- **Fatigue threshold respected** (`apps/kid/src/App.tsx`): the session-completion
  effect now reads Moni's profile BEFORE `recordSession` resets `sessionRounds`,
  and routes to the break screen when the finished session crossed the fatigue
  threshold (`prof.sessionRounds >= prof.attention.fatigueThreshold`, default 12
  when never measured). A 5-round single-skill lesson never interrupts; a long
  world sweep (up to 30 rounds) triggers the gentle pause.
- **Break screen**: a new `"break"` screen — soft sky theme, Nova gently invites
  a stretch, "Stretch time, {name}!" + warm body copy, a bobbing 🧘. Fully
  localized EN + BN (`breakTitle/breakBody/breakRest/breakKeepGoing`).
- **Never blocks forever**: "I'm good — keep going!" is always one tap away and
  lands on the regular done screen (celebration + next-round button intact).
  The break flag (`breakPendingRef`) is cleared at every session start and on
  both break buttons, so a fresh session starts at 0 and the break can never
  loop or hard-stop play.
- **Offline**: pure local store read; no network, no server.
