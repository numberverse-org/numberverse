# Work Order — #180: English prepositions (in, on, under, behind)

**Status:** ✅ Merged via PR #___

## Problem
Band 2 English needed spatial grammar — the prepositions that tell where things
are (in, on, under …). The most memorable way to teach them is to physically
MOVE an object to the spoken place.

## Fix
New `PrepositionsScene` (`apps/kid/src/game/PrepositionsScene.ts`), band 2, scene
key `Prepositions`, skill `en-prepositions` (c2-english-6), game
`game-prepositions` (difficultyLevels `[0,0,0,0,0,0]` — semantic variety).

**Mechanic — drag-to-place (done-when):**
- **8 prepositions (done-when):** in, on, under, behind, in front of, next to,
  above, between — each with its own distinct drop zone around the reference box
  (in = inside the crate outline, on = top edge, under = below, behind = peeking
  from behind the solid box, in front of = over it, next to = beside, above =
  high up, between = between two boxes).
- The instruction is SPOKEN and shown: "Put the cat ON the box!" (8 emoji
  objects: 🐱🐶🐦🐸🐭🦆⚽⭐). The kid DRAGS the object to the right spot;
  a correct drop snaps it home, pops the box in/on/under result sentence
  ("The cat is on the box!"), and speaks it. A wrong drop snaps back, shakes,
  and re-speaks the instruction.
