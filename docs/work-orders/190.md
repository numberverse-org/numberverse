# Work Order 190 — Math: doubles & near-doubles

**Issue:** #190
**Status:** DONE (PR #___)

## Problem
Band 1/2 kids need a strategy game (not just drill) that teaches the doubles
facts and transfers that skill to near-doubles (5+6 = double 5 + 1).

## Fix
New `DoublesScene` — free-paced strategy game (no timer: the strategy is the
lesson, not speed):
- **Doubles song + drill:** a 🎵 button chants the doubles up to the current
  range ("Double 1 is 2. Double 2 is 4 …", Bangla for the BN locale). Each
  question shows "a + a = ?" with two equal dot rows as the visual.
- **Near-doubles transfer:** the second half of every round shows "a + (a+1) = ?"
  with the bottom dot row one longer (extra dot green) and a strategy hint
  "double {d} = {dd} · +1 = {n}".
- **Spoken strategy:** every correct answer speaks it — doubles "Double 5 is 10!",
  near-doubles "5 + 6 = double 5 + 1 = 11!" — reinforcing the mental shortcut.
- Wrong tap → shake + dim + reveal + the strategy hint stays visible.

Wired as skill `en-doubles` (band 2 math, c2-math-8, class 2), game
`game-doubles`, scene key `Doubles`, bg "sky". i18n: 7 new dbl* keys (EN + BN)
using the existing {placeholder} interpolation. Bangla digits for the BN locale.
