# Work order #338 — Moni: per-skill goal planner for parents
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-338`

## Goal
Show the next 3 skills Moni recommends a kid practice, with why.

## Done when
- [x] 3 recommendations
- [x] Plain-language why
- [x] Offline

## What shipped
- **Core planner** (`packages/core/src/moni/`): `MoniPlan` now carries
  `recommendations` — the top 3 practice goals, most urgent first:
  1. the focus skill (`focus` — the misconception / weakest / next challenge),
  2. the next weakest skills (`weak`),
  3. anything due for spaced review (`review`, with `inDays`).
  Each has a `reasonCode` (localizable) plus a plain English `reason`.
- **Parent Moni card**: a "Moni's 3 next skills" list renders the goals with
  skill title (BN title shown too) and a plain-language why — "the main focus
  right now" / "still needs work" / "brush up in N days", fully i18n'd EN + BN.
- **Offline**: everything is computed locally from the store's own Moni
  profile + mastery — no network.
