# Work order #332 — Moni: learning-style surface
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-332`

## Goal
Show the kid's detected learning style (fast / steady / social) as a fun
Nova badge — one look and the kid knows how Moni sees them.

## Done when
- [x] Style derived
- [x] Kid-safe wording
- [x] i18n clean

## What shipped
- **Style derived**: `deriveLearningStyle(style: MoniStyle)` in core
  (`packages/core/src/moni/style.ts`) — pure + deterministic + offline.
  `fast` = answers quickly (speedTendency > 0.6); `social` = not zippy but
  engaged across ≥4 games (a variety-seeker — "plays with everyone");
  `steady` = everything else (careful, methodical).
- **Kid-safe wording**: a small gold-rimmed pill floats under the streak in
  Nova's room — `⚡ Speed Sprinter` / `🐢 Steady Pal` / `🦉 Friend of All`
  (EN) and `⚡ দ্রুত তারা` / `🐢 ধীরে সুস্থে` / `🦉 সবার বন্ধু` (BN). Hidden
  until Moni has seen ≥4 rounds (same bar as the parent card), so it never
  shows a wrong guess for a brand-new kid.
- **i18n clean**: badge labels live in the scene's own `NOVA_T` table (EN +
  BN, typed `Record<LearningStyle, string>`); audit passes.
