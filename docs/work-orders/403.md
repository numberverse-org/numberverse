# #403 — Settings redesign (kid-facing) + fix double-TTS

**Status:** ✅ review → merged → released

## What changed

### 1. Double-TTS fix (neural AND Web Speech both speak)

**Root cause (two races):**
1. `neuralSpeak` never canceled in-flight Web Speech. A Bangla neural line could
   start while an English (or fallback) Web Speech line was still audible —
   both engines speak at once. `webSpeak → neuralCancel()` was already handled;
   the mirror direction (neural → web) was not.
2. A superseded neural line still fell back to Web Speech. When a newer
   `neuralSpeak` bumped `synthToken`, the older line's `playBlob` resolved
   `false`; speech.ts's `.then((played) => !played && token === speakToken)`
   then called `webSpeak` — and because the voice-picker preview calls
   `neuralSpeak` directly (bypassing `speak()`'s token bump), `speakToken`
   could still equal the old token → BOTH engines speak the old line while the
   new line plays.

**Fix:**
- `neuralVoice.ts` — new tri-state `NeuralOutcome = "played" | "failed" | "superseded"`.
  - `playBlob` resolves `"played"` on completion, `"failed"` on error / iOS lock.
  - `neuralStopPlayback()` resolves `"superseded"` (a newer line took over).
  - `neuralSpeak` returns the outcome; `"superseded"` (token mismatch / canceled)
    vs `"failed"` (genuine) is now distinguishable by the caller.
  - New `stopWebSpeech()` — called at the top of `playBlob`, so a neural line
    cancels in-flight Web Speech right before it actually plays. Mutual
    exclusion is now symmetric across both engines.
- `speech.ts` — Bangla fallback to Web Speech fires ONLY on `"failed"`
  (voice not ready / synth error / iOS audio locked). `"superseded"` never
  falls back — that was the exact double-speak path.

### 2. Kid-facing Settings redesign

Rewrote the settings screen (App.tsx) + new styles (styles.css):

- **Grouped sections** with clear eyebrow headers: **Family** (Parent Portal
  door + in-app analytics + account/sign-in + signed-in aggregate card),
  **Sound & voice**, **Language**, **Learning** (syllabus + progress storage).
- **Real toggle switches** for Music and Fullscreen (`.switch` — green track +
  sliding thumb, 44px+ tap targets) instead of text buttons.
- **Language** is a two-choice pill picker (English / বাংলা) with an obvious
  active state — a toggle hid the other option.
- **Voice card** shows what Bangla is ACTUALLY spoken by: neural speaker label
  (🧠 badge) when ready, else the best device voice; live test; the 4-voice
  neural picker with preview; a download-progress line while the voice loads;
  and an honest "reading is off — a parent turned it off" note.
- **Learning card** shows a friendly colored sync line (dot + message) instead
  of a cryptic pill: "✓ All stories saved on this device" / "Saving…" / etc.
- Version footer replaces the old About card.
