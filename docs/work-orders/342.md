# Work order #342 — Adaptive: hint-ladder depth by confidence
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-342`

## Goal
Hint escalation depth scales with Moni confidence (unsure → more scaffolding).

## Done when
- [x] Depth tiers
- [x] Linked to confidence
- [x] i18n clean

## What shipped
- **Depth tiers** (`hints.ts`): `HintDepth` (0 fragile / 1 steady / 2 sharp),
  `confidenceDepth(score)` maps a Moni confidence score (0–1) to a tier, and
  `revealAtDepth(depth)` gives the miss number where the reveal fires.
- **Linked to confidence**: `hintWrong()` reads the current kid's Moni profile
  (`wrongLedger.kidId()` → `useKidStore.getState().moni[kidId].confidence.score`)
  and scales the reveal threshold:
  - confidence < 0.4 (fragile) → reveal at miss **2** — catch them before a
    miss snowballs (the miss-2 coaching banner + reveal fire together)
  - 0.4 – 0.7 (steady) → reveal at miss **3** — the classic ladder
  - > 0.7 (sharp) → reveal at miss **4** — give the confident mind room to
    figure it out
- Miss #1 (soft nudge) and the coaching banner / half-clear stay exactly as
  they were — only the *reveal point* moves.
- **Exposed kid id**: `wrongLedger.kidId()` getter (wrongLedger.ts) so the hint
  system can look up the right kid's Moni profile without touching any scene.
