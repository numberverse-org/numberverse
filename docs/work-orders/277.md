# #277 — Land trophy room

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

No keepsake for the big milestone of mastering a WHOLE land. Acceptance:
**land trophies** · **celebration on earn** · **offline**. (Issue says "6 land
trophies" — since #20 shipped Jungle + Polar there are now **7 lands**, so the
room shows all 7.)

## Fix

A **🏆 Trophy Room** screen (a shelf of one trophy per land) reachable from a
🏆 button in the worlds screen header — right where the kid sees the lands.

- **Store** (`store.ts`) — `NovaState.trophies: number[]` persists earned
  land band-ids; `novaSyncTrophies(kidId, earned) → number[]` merges the
  currently-mastered band ids and returns the **newly-earned** subset (same
  pattern as #283 badges).
- **Celebration on earn** — a `useEffect` watches the fully-mastered lands
  signature; a land that crosses `mastered === total` fires `tada()` + a
  spoken cheer in the app's language, exactly once.
- **Trophy room screen** — a shelf of all 7 lands: earned trophies glow +
  pulse 🏆, locked ones are dimmed 🔒 with a gentle "master every skill to
  earn" hint + a live X/Y progress readout; empty state when nothing earned.
- **i18n** — 6 `Strings` entries EN + BN (`trTitle/Sub/Earned/Locked/Empty/
  NewSpeak`), Bangla digits via `bnNum`.
- **Offline** — reads local mastery only; nothing leaves the device.
