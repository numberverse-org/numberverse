# #4 — Parent: weekly streak + playtime vs cap

## What
Parent dashboard "This week" card now shows:
- 🔥 **streak badge** — consecutive active days (ending today, or yesterday while
  today is still quiet so the streak stays alive until the day ends).
- **Today X / cap Y min bar** — today's minutes vs the DAY's cap, using the same
  `weekdayLimits()` array the portal's own limit editor uses → matches what the
  kid app enforces (legacy flat `daily_limit_min` and Mon..Sun weekday caps both
  respected; defaults 45 school / 90 weekend when nothing set).
- The "min played" tile is relabeled **"minutes this week"** (EN+BN).

Fully derived from data already loaded with the dashboard (weekly + settings) →
works offline after load; a refresh rolls the day forward.

## Backend
`GET /kids/{id}/weekly` now returns `streak` — computed from the FULL history
(distinct played dates, cheap) so streaks longer than the 7-day window still
count. `WeeklyOut.streak: int = 0`.

## i18n
`STREAK_LANGS` EN + BN map in `apps/parent/app/page.tsx` (same country-pack seam
as `PAUSE_LANGS`). New locale = new key, no rewrites.

## Files
- `apps/api/app/schemas.py` — `WeeklyOut.streak`

- `apps/parent/app/page.tsx` — `STREAK_LANGS`, derived values, weekly-card UI
