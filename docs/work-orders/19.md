# #19 — Garden/pet expansion: feed + grow, new species

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

The pet is the emotional hook, but after adoption it was static. Issue's
acceptance: **feed grows the pet; milestones unlock a new species; coin economy
balanced.**

## Fix

Deepened the pet loop, locale-aware (names via the NOVA_SPECIES registry —
adding a language or a species is pure config, #131):

- **Species registry** — `NovaSpecies` + `NOVA_SPECIES` in `store.ts`:
  `owl` (starter, free) → `cat` (40 🪙, unlock stage 1) → `peacock` (80 🪙,
  unlock stage 2) → `dragon` (120 🪙, unlock stage 3). Each has its own
  egg→grown emoji evolution; `speciesById` / `speciesEmoji` helpers.
- **Milestone gate** — `unlockStage` ties adoption to pet growth: a new
  species appears once the pet REACHES that growth stage ("milestones unlock
  a new species").
- **Coin economy** — one-time coin cost scales with the species; starter owl
  is always free. Feeding still gives +0.2 grow once daily (existing
  `petFeed`), mastery/session growth unchanged.
- **Store action** — `petAdopt(kidId, speciesId)`: validates milestone +
  coins, deducts, switches `NovaState.species`. Growth carries across species
  (petStage is shared) so milestone progress is never lost.
- **Nova room UI** — new `🐣` FAB → "Pet Friends" bottom sheet (mirrors the
  outfit shop): each species card shows its face at the pet's CURRENT stage,
  locked (🔒 grows to unlock) / affordable (adopt + 🪙) / adopted (✅ mine)
  states; tap adopts with a win chime + sparkle. A small companion emoji
  floats beside Nova for adopted non-owl species.
- **Home + done screens** — pet badge and growth toast now use
  `speciesEmoji(species, petStage)` and the species name; stage labels made
  species-generic (Egg/Hatchling/Young/Grown) so they read true for every
  species in every locale.

## Files
- `apps/kid/src/store.ts` — NovaSpecies registry, species helpers, `species`
  state, `petAdopt` action
- `apps/kid/src/game/NovaScene.ts` — species sheet + 🐣 FAB + companion + NOVA_T
  keys (en/bn)
- `apps/kid/src/App.tsx` — reactive `petSpecies`, species-aware pet badge +
  growth toast, generic stage labels (EN + BN)
