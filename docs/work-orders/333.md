# Work order #333 — Moni: parent-adjustable strictness
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-333`

## Goal
Let parents set how hard Moni pushes a kid — gentle / steady / challenging —
so tone and difficulty deltas match the child (and the family's philosophy).

## Done when
- [x] Per-kid setting
- [x] Plan respects it
- [x] Offline

## What shipped
- **Per-kid setting**: `MoniStrictness = "gentle" | "steady" | "challenging"`
  (core `types.ts`). The parent Moni card gained a 3-option segmented selector
  (`moniStrictness*` i18n keys, EN + BN) saved per kid via
  `moniStrictness: Record<kidId, MoniStrictness>` + `setMoniStrictness()`
  in the kid store.
- **Plan respects it**: `moni.plan(profile, mastery, catalog, params,
  strictness?)` now overrides its automatic tone (gentle/steady/challenging)
  AND shifts the difficulty delta ±1 on top of the focus-selection math
  (`gentle → -1`, `challenging → +1`, `steady → 0`, clamped ≥ 1). `moniPlanFor`
  in App.tsx passes the kid's stored strictness (defaults `"steady"`).
- **Offline**: the whole Moni block — `moni`, `moniWrongStreak`, and the new
  `moniStrictness` — is now persisted via zustand `partialize` (this also fixed
  a pre-existing gap where Moni profiles reset on reload).
