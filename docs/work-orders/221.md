# Work Order #221 — English: synonyms & antonyms pairs

**Status:** DONE · **PR:** #548 · **Branch:** feat/221-synant · **Merge:** main

## Problem
Band-3 vocabulary gap: learners meet single words but not word relationships.
Issue asks for 15+ synonym and 15+ antonym pairs, picture-backed, i18n clean.

## Fix
New `SynAntScene` — "Same or opposite?": a mode pill (🔵 Same meaning /
🟠 Opposite) shows above a target word + emoji; the kid taps the matching word
from 3 options.

- **16 synonym pairs** (happy→glad, quick→fast, begin→start…) + **16 antonym
  pairs** (hot→cold, fast→slow, up→down…) — each with an emoji picture hint.
- **Half/half mixing** — every round draws ⌈n/2⌉ synonyms + the rest antonyms,
  shuffled together, so kids practise both relations in one round.
- **Separate shuffle-bags** for SYN and ANT (per-bag 16-permutations, boundary
  repeat avoided) + **round-level dedupe** so a bag refill never repeats a
  target shown earlier in the round.
- **3 string-distinct options** — distractor pool excludes the correct answer,
  correct appears exactly once.
- Correct tap → "Yes! happy → glad" float + audio + green highlight + the full
  pair spoken; wrong tap → gentle "Try again" nudge (never a penalty).
- Ladder `[6,6,8,8,10,10]`, `ROUNDS_TO_FINISH = 3`, bg "candy".
