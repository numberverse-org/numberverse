# Work Order 196 — Math: fractions — parts of a set

**Issue:** #196
**Status:** DONE (PR #___)

## Problem
Band 2/3 kids need fractions taught as PARTS OF A SET — not just parts of a
whole: 1/2 of 8 apples is 4 apples, seen and tapped.

## Fix
New `FracSetScene` — tap-the-subset game:
- **Group visuals:** a uniform group of 🍎 (4–16 identical fruits) is shown in a
  grid with row/column badges-free clean layout.
- **Tap the correct subset:** the prompt says "Tap 1/2 of 8". The kid taps fruits
  to select them (green ring, toggleable) and presses ✅. Correct → selected
  fruits bounce, "1/2 of 8 = 4" floats up, and the count is spoken. Wrong →
  "Tap 4 items" hint.
- **Fractions:** denominators 2 (lvl 1–2), 2–3 (lvl 3), 2–4 (lvl 4+); numerator
  1..den−1. Group = den × 2..4 so the target is always a whole number ≥ 1.
- Check button is the only submit — the kid can freely toggle before checking.

Wired as skill `en-fracset` (band 3 math, c3-math-8, class 3), game
`game-fracset`, scene key `FracSet`, bg "candy". i18n: 5 new fs* keys (EN + BN).
Bangla digits for the BN locale.
