# #281 — Daily login calendar reward

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

No visual reward for the habit of coming back every day. Acceptance:
**7-day cycle** · **within the daily cap** · **offline**.

## Fix

A 7-tile login calendar on the home screen with a **growing coin bonus per
consecutive play day** — reuses the streak/days state already maintained by
`novaCompleteSession`, so there is no new clockwork to keep in sync.

- **Store** (`store.ts`) —
  - `NOVA_CALENDAR_REWARDS = [3, 4, 5, 6, 7, 8, 10]` (each sits inside the
    anti-grind cap `NOVA_DAILY_CAP = 20`).
  - `calendarCycleDay(streak)` → position 1..7 in the cycle
    (`((streak - 1) % 7) + 1`).
  - `NovaState.calendarDay` — last ISO date the bonus was claimed ("" = never).
  - `novaClaimCalendar(kidId) → number` — collect today's tile. Eligible only
    **after the day's first session** (`lastDay === today`) and **once per
    day** (`calendarDay !== today`). Reward is min(reward, cap − earnedToday),
    so a child who already hit the cap gets a genuine zero (no leak, no
    over-grind). Returns the coins granted so the UI can cheer.
- **Home screen** (`App.tsx`) — a `.cal-chip` strip between the Daily Quest
  and the pet card. Each tile is one cycle day: past ✓, today pulsing
  "🪙N" (tap to collect → `tada()` + spoken cheer), future 🔒. The cycle
  position is derived from the streak anchor: played today → current tile;
  played yesterday → next tile (today extends the streak); missed → restart
  at day 1 (streak kindness, no guilt). Fully offline (local store only).
- **i18n** — 7 new `Strings` entries EN + BN (`calendarTitle/Hint/DayOf/
  Claim/Claimed/Locked/ClaimSpeak`), localized with `bnNum` for Bangla digits.
- **CSS** (`styles.css`) — `.cal-chip/.cal-head/.cal-strip/.cal-tile` with
  done/wait/claim/future states + `calPulse` on the claimable tile.
