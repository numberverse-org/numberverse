# #254 — Parent: dashboard light/dark theme

**Status:** ✅ Shipped (PR #568)
**Priority:** low · parent-facing

## Goal
A simple light/dark theme toggle for the parent dashboard.

## Done when
- [x] Persisted choice — `nv_parent_theme` localStorage, applied as `theme-light` class on `<html>` on boot; `storage` listener keeps portal tabs in sync
- [x] Both themes accessible — every ink/surface color in `globals.css` moved to CSS variables; `:root` = dark (default, zero visual change for existing users), `html.theme-light` = light; native inputs follow via `color-scheme`
