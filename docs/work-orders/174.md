# Work Order — #174: Bangla riddle time (ধাঁধা)

**Status:** ✅ Merged via PR #___

## Problem
Band 2 needed a comprehension/vocabulary game: solving short spoken riddles with
picture answers — training listening comprehension, inference, and word-to-world
mapping in a playful way.

## Fix
New `RiddleScene` (`apps/kid/src/game/RiddleScene.ts`), band 2, scene key
`Riddle`, skill `bn-riddle` (c2-bangla-11), game `game-riddle`
(difficultyLevels `[3,3,3,4,4,4]` = option count).

**Mechanic — spoken clue → tap the picture answer (done-when):**
- 18 kid riddles (🍌 কলা, 🐕 কুকুর, 🌈 রংধনু, 🐘 হাতি, 💡 বাতি …), each with a
  big ❓ that flips to the answer emoji on solve. The clue reads itself aloud
  (Web Speech bn) with a 🔊 replay button.
- **Hint ladder** (done-when): wrong #1 → "এটা একটা {cat}।" (category: ফল/পশু/
  প্রকৃতি/পাখি/পোকা/গাছপালা/যানবাহন/জিনিস) · wrong #2 → "উত্তরটা '{letter}'
  দিয়ে শুরু।" (first letter) · wrong #3 → the answer is revealed and spoken and
  play moves on. Every wrong tile is retired so options narrow to the right one.
- Correct → answer name spoken aloud + win sound. Option count 3→4 across 6
  tiers.
