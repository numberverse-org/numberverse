# #7 — Parent debug card (local-only diagnostics)

## What
A 🩺 **Diagnostics** card in the parent portal, collapsible, that reads ONLY
this browser — no analytics path exists:
- Last 20 window errors + unhandled rejections (in-memory ring buffer, never
  written to disk, dies on reload).
- Service-worker version (if any).
- Last successful API sync time + online/offline status.
- On-device voice engine count.
- Export button → copies a text blob to clipboard (falls back to a download).
  Contains zero PII: no kid names/ids/emails — browser env facts + error strings
  only.
