# #128 — TLS cert rotation check automation

**Status:** ✅ done (merged — issue CLOSED; cron armed on box)

## Problem

No automated check that the Cloudflare-served cert is valid / near expiry.

## Fix

`infra/tunnel/cert-expiry-check.sh` — a daily tripwire that connects to
`kids.munna-khan.xyz:443`, reads the served cert's enddate, and:
- logs days-left to `/tmp/nv-cert-check.log`
- **exit 1 + ⚠ alert line** if under 14 days (Cloudflare auto-rotation broke)
- **exit 1 + ✖✖** if expired

TLS is edge-terminated by Cloudflare (the box has no origin cert — the tunnel
is token-mode). Cloudflare rotates automatically; this check catches any break
in that.

## Verification (live box, 2026-08-12)

```
kids.munna-khan.xyz cert: 38 days left (expires Sep 20 22:12:36 2026 GMT)  exit=0
```

Cron armed: `0 7 * * * bash .../cert-expiry-check.sh` (daily).
