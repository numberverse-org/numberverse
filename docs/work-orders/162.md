# Work Order #162 — Bangla: NCTB rhymes tap-along (ছড়ার গান)

**Status:** ✅ Merged via PR #489

## Problem
Band-1 kids (ages 2–4) learn language through rhyme. No Bangla recitation game
existed — `game-countsong` is the math number-song. Kids need the classic NCTB
nursery rhymes sung aloud with a tap-along that builds word-shape + rhythm.

## Fix
New `RhymeTimeScene` (key `RhymeTime`, skill `bn-rhymes`, game `game-rhymes`,
band 1):

- **5 classic NCTB/traditional Bangla rhymes** (done-when: 5) — হাট্টিমাটিম টিম,
  আয় রে ভাই, খোকা ঘুমালো, বৃষ্টি পড়ে টাপুর টুপুর, চাঁদ উঠেছে. Each a 2-line
  verse split into 6–9 tappable word chips laid out as centered lines.
- **Tap-along:** Nova "sings" each word in warm Bangla; the kid taps the glowing
  word. Matching is by CHIP IDENTITY (not string) so repeated words (আয় … আয়)
  still have exactly one correct chip. Wrong chips just re-pulse the target +
  re-speak it — never a fail.
- **It literally sings:** every correct tap plays the next note of a C-major
  pentatonic ladder, so tapping along builds the melody; the verse finishes with
  a closing arpeggio + the full rhyme recited (🔊 toggle re-reads anytime).
- **Guide ladder** `[2,2,1,1,0,0]`: levels 0-1 keep a gold ring on the word,
  2-3 let it fade after being heard, 4-5 are listen-only.
- 1 rhyme per round, 3 rounds per level.
