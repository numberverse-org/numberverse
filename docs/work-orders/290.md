# #290 — Kids: mastery confetti + spoken cheer

**Status:** in progress (2026-08-13)

## Problem

When a skill crosses the mastery bar mid-session, the app quietly plants a
garden flower and grows the pet — the celebration was deferred entirely to the
done screen ("🌟 New skill mastered!"). The INSTANT itself deserved a moment.

## Fix

In `onRoundDone` (App.tsx), when a skill just crossed `MASTERY_THRESHOLD` AND is
newly mastered this session (guarded by `masteredBeforeRef` — one cheer per
skill, and already-mastered skills never re-cheer):

- `cancelSpeech(); tada();` + `speak(t.masterySpeak(title))` — a spoken cheer
  naming the skill, in the app's language (EN: "Wow! You mastered X! 🎉",
  BN: "বাহ! তুমি X আয়ত্ত করেছ! 🎉").
- `confettiBurst(scene, width/2, min(height*0.35, 240), 44)` — an in-scene
  colored confetti burst, top-center, from the existing celebrate.ts engine.

New `masterySpeak` i18n key (interface + EN + BN); `confettiBurst` imported from
celebrate.ts.
