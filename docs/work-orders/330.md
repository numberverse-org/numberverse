# Work order #330 — Kotha: privacy-scrubbed cross-kid aggregates
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-330`

## Goal
Opt-in aggregate insights (e.g. 'most common misconception in your class') with zero kid identity.

## Done when
- [x] Aggregate queries
- [x] No PII
- [x] Parent opt-in

## What shipped
- **Aggregate queries**: `GET /api/v1/stories/aggregates` (any signed-in
  parent) returns `contributing_kids`, `total_stories`, `success_rate`, the
  top-5 misconception codes, the error-kind distribution, and the top-5
  trickiest skills — all computed ONLY from stories of opted-in families.
- **No PII**: the response carries zero kid identity — no names, no kid ids,
  no emails. Just counts, rates, and curriculum/skill ids. The class-insights
  card renders codes via a local label map and skill titles; the note spells
  out the policy.
- **Parent opt-in**: `Profile.aggregate_opt_in` (default OFF), toggled via
  `PATCH /auth/me` (parent settings → "🔭 Class insights" card). **Give-to-get**:
  the aggregates endpoint returns **403** until the caller opts in, so only
  parents who share can read the shared picture.
