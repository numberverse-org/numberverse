# #289 — Long-term achievements book

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

No long-term milestones album — badges stop at the first 4 goals. Acceptance:
**12+ achievements** · **unlock animation** · **offline**.

## Fix

A **📚 Achievements** album (More menu → "Achievements") tracking milestones
across WEEKS, all derived from lifetime local stats. **18 achievements**, each
a slow-burn goal: sessions (1/25/100/250), stars (100/500), mastered skills
(5/10/25/40), streaks (14/30 days), lands (first/all), coins (100/500),
pet growth (fully grown), and every species adopted (zookeeper).

- **Celebrate-once** — same pattern as badges/trophies: App computes the
  currently-earned set from local stats → `novaSyncAchievements` merges into
  the persisted `achievements[]` and returns NEWLY-earned → home fires
  `tada()` + a spoken cheer exactly once per achievement.
- **Unlock animation** — a freshly-earned card on the album screen pops with
  a glow (`@keyframes achUnlock`), then settles into the earned glow. The
  other cards keep the badge-grid look (earned / locked / tap-to-hear).
- **Zookeeper is real** — `petAdopt` now records every adopted species in
  `adoptedPets[]` (migration-safe: re-adopt dedupes), so "adopt all pets" is
  a true persisted milestone.
- **Offline** — local stats only; no network.
- **i18n** — 6 new `Strings` entries EN + BN (`achTile/Title/Sub/Unlocked/
  Locked/NewSpeak`); all 18 names + hints are locale-packed in the
  `ACHIEVEMENTS` config (#131).

## Files
- `apps/kid/src/store.ts` — `achievements` + `adoptedPets` in `NovaState`,
  `petAdopt` records adoptions, `novaSyncAchievements` (celebrate-once merge)
- `apps/kid/src/App.tsx` — `ACHIEVEMENTS` config (18), `"achievements"` screen,
  celebration effect, More-menu tile, Strings EN + BN
- `apps/kid/src/styles.css` — `.ach-*` grid/cards + `achUnlock` pop animation
