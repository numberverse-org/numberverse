# Work Order #238 — Parent: weekly learning narrative from Kotha

**Status:** DONE · **PR:** #554 · **Branch:** feat/238-kotha-weekly-narrative · **Merge:** main

## Problem
The weekly report shows numbers (rounds, %, minutes) but no plain-language
"here is what your kid actually learned and struggled with this week". Kotha
stories already record every round's skill, outcome and Moni's diagnosis — they
just weren't surfaced to parents as a readable summary.

## Fix
New "📖 {kid}'s week in words" card on the parent dashboard (right after
Reading & stories) that turns the last 7 days of Kotha stories into a warm,
plain-language paragraph in **English + Bangla**.

- **Generated from stories** — `GET /kids/{kid_id}/stories?limit=500` is fetched
  with the rest of the per-kid dashboard data (`refreshAll`/`switchKid`), filtered
  to the last 7 days client-side. The builder ranks the week's skills, picks the
  strongest (most correct) and trickiest (most wrong), and names the most-repeated
  misconception on the tricky skill from the fingerprint code catalog
  (`overcount-1`, `off-by-ten`, `reversal` …) with a plain-language label.
- **Bangla+EN** — every sentence is generated in both languages, and a language
  toggle switches the editable textarea between them. Skill titles come from the
  `@numberverse/core` catalog (`title` + `titleBn`), so new skills automatically
  appear in both languages.
- **Edit-safe (never sends to cloud)** — generation is pure + client-side from
  stories the portal already holds; the parent's edits are stored only in
  localStorage (`nv_kotha_nar_{kidId}`), with a ↺ Regenerate and 📋 Copy button.
  Nothing the parent types is ever sent to any server.
