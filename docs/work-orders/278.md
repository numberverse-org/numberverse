# #278 — Nova seasonal outfits (Eid, Boishakh)

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Limited seasonal Nova outfits (panjabi, sharee theme) unlockable with coins.
Acceptance: **2 seasonal sets** · **coin-purchasable** · **i18n clean**.

## Fix

Two festival-gated sets that live entirely in the **locale-pack architecture**
(#131): availability is config from the locale's festival windows, so another
country's festival = one config entry, not a rewrite.

- **Registry** (`store.ts`) — `NovaOutfit` gained an optional `festival?`
  field; 4 new outfits in 2 sets (reusing existing body kinds so Nova wears
  them with zero new texture code; the card emoji + name carry the look):
  - **Eid** (`eid_fitr`): `eid-panjabi` 👔 (25 🪙, tunic), `eid-topi` 🧢
    (20 🪙, hat)
  - **Boishakh** (`boishakh`): `boishakh-sharee` 🥻 (30 🪙, tunic),
    `boishakh-fan` 🪭 (20 🪙, bow)
- **Coin-purchasable** — same `novaBuy` flow, but now festival-gated in the
  STORE (`novaBuy(kidId, outfitId, festivalKey)`): a seasonal outfit is only
  purchasable while its festival is active in the current locale — enforced
  store-side so even a tampered call can't buy off-season.
- **i18n clean** — the Nova scene's NOVA_T (EN + BN) gained `seasonal`
  ("🎉 {festival} only" / "🎉 শুধু {festival}") + `festEid` ("Eid"/"ঈদ") +
  `festBoishakh` ("Pohela Boishakh"/"পহেলা বৈশাখ"). The active festival key
  comes from `currentFestival()` (config, #131).
- **Shop UX** — seasonal outfits always appear in the shop as a collectible
  teaser: off-season they show `🔒 🎉 {festival} only` (dimmed, tap = Nova
  says the seasonal hint); during the festival they buy normally and Nova
  wears them. Pagination grew 8 → 12 outfits automatically (3/page).

## Files
- `apps/kid/src/store.ts` — `NovaOutfit.festival?`, 4 seasonal outfits,
