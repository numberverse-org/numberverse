# Work order #31 — feat: per-line neural WAV cache (IndexedDB LRU) + idle pre-synth of common phrases
> milestone: v14 — polish & perf · branch: `feat/issue-31`

## Acceptance criteria (from the issue)

**Why (kid-first):** the neural voice's *first-run* speed is fixed by #28 + the upcoming #29 (int4). But **every session** still pays a per-line synthesis cost: each spoken phrase runs phonemizer (~50–200ms) + ORT session inference (~100–500ms) on the WASM worker. The game repeats the same short phrases constantly (counting 1–10, `ঠিক আছে`, `নোট`, question stems) — so a per-text WAV cache makes the 2nd+ occurrence instant, and idle pre-synthesis makes the common ones instant from the very first line of a session.

**Acceptance criteria**
- [x] **WAV LRU cache in IndexedDB** (`neuralVoice.ts`): DB `nv-wav-cache`/store `waves`, keyed `"${speakerId}:${text}"`, cached `{blob, ts, bytes}`. `getBlobFor()` in `neuralSpeak` — hit plays straight from cache (no synth), miss synths then stores. 30MB LRU cap with oldest-first eviction (safe same-task IDB tx pattern). Survives reload → visit 2+ benefits. Only short texts (≤100 chars) cached so unique long lines don't pollute.
- [x] **Idle pre-synthesis of common phrases:** `warmCommonPhrases()` after model-ready — Bangla words 0–20 (mirrors `bnNumber()` in speech.ts, must stay in sync) + 8 universal praise/prompt words, in idle batches of 3 with 120ms yields so real speech interleaves. Cache-first → re-visits are a no-op sweep.
- [x] Respect queue/latest-wins semantics exactly — cache path feeds the same `playBlob` + token guard; `neuralStopPlayback`/`neuralCancel` unchanged.
- [x] **Measure:** `neuralStatus().cache` = `{hits, misses, hitRate}` persisted in localStorage (`nv_cache_metric`, no network). Voice card shows `voiceCacheHit(pct)` (EN+BN) once any line has been spoken.
- [x] `tsc --noEmit` clean · audit clean · oracle 35/35 CLEAN ✓ (CI to verify on the PR)

**Guardrails:** privacy stays the moat (cache is on-device, nothing leaves the device) · Web Speech fallback untouched · iOS audio-unlock untouched · no ads/analytics.
