## Notes
- Zero backend changes — reuses the #251 full-history cache (`archActivity`).
- Mastery attribution is BKT-exact under default adaptive params (p_learn .1 / p_guess .15 / p_slip .1), the common config; a future server config override could shift crossings, which is acceptable for a parent-facing timeline.
- Day bucketing is LOCAL calendar days (matches the portal's `fmtTime`), unlike the archive's UTC months.
