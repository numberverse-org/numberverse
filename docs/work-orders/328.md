Surface review prompts for skills due per Moni's spaced review days.

## What shipped
- **Per-skill, confidence-based intervals** (`packages/core/src/moni/planner.ts`):
  a mastered skill (pMastered ≥ 0.8) now refreshes on a real ladder instead of
  every mastered skill being lumped onto a flat 1-day review. Each skill's own
  solidity (mastery × streak consistency) picks the rung from the `reviewDays`
  ladder [1, 3, 7, 14]; a fragile child (low recoveryRate) pulls every interval
  a rung shorter so weak-but-mastered skills resurface sooner.
- **Due list per kid** (`MoniPlan.dueReviews`): skills past their due date come
  back most-overdue-first, each with `inDays: 0` + `overdueDays`. Upcoming
  reviews stay in `reviewSchedule` sorted by soonest. The parent-facing
  `recommendations` now lists due reviews first (most urgent), so the tutor
  card shows what actually needs brushing up.
- **Gentle prompts** (`apps/kid/src/App.tsx` home screen): a soft glass chip
  between Play and the journey path — "Moni says: a quick review keeps it
  sharp — no rush!" with up to 2 tappable skill pills that start that skill's
  session via `startSingleSkill`. Non-blocking, never a lecture, disappears
  when nothing is due. Fully localized EN + BN.
- **Offline**: everything reads the local Zustand store (per-kid `skills` +
  `lastPractice`); no network, no server, no data leaves the device.
- **Deterministic plan**: `plan()` accepts an optional `now` (epoch ms) and
  `moniPlanFor` passes `Date.now()` — review-due math is testable and stable
  within a render. `SkillMasteryLike` grew an optional `lastPractice`; a
  mastered skill with no timestamp (older saves) surfaces once as a gentle
  first refresh.
