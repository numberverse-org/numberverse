## What shipped

A view showing the skills an advanced kid skipped ahead past, and WHY — logged,
offline-friendly, parent-facing.

### Backend (`apps/api`)
- **`AccelerationLog`** model — every "skipped ahead" entry: `skill_id`, `reason`
  (`easy|know|moving-on|parent`), `band_from`/`band_to` (the world-band jump),
  deduped on the client's durable-outbox `uid` (unique `(kid_id, uid)`, exactly
  like `learning_stories`). Auto-created by `create_tables()`.
- **`AccelerationIn`/`AccelerationOut`** schemas — reason pattern-validated,
  bands 1..5.
- **`POST /acceleration`** (202, WRITE_RATE_LIMIT, per-kid ownership, band-lock,
  `INSERT … ON CONFLICT DO NOTHING`) + **`GET /kids/{kid_id}/acceleration`**
  (newest first, ownership-checked).

### Kid app (`apps/kid`)
- **Durable outbox** — `accel` in the store (persisted, like `stories`), drained
  by **`syncAccel()`** to `POST /acceleration` on the same heartbeat /
  reconnect / foreground events; `drainAccelIfFull()` quota guard.
- **`accelSkip()`** store action — marks the skill mastered locally (journey
  advances) AND logs the entry with the band jump.
- **"⏭ I already know this"** skip chip on the world-detail screen (next to the
  Play button), with a toast + screen-reader announcement. Purely additive —
  the parent sees every skip.

### Parent portal (`apps/parent`)
- **`AccelerationRow`** + **`getAcceleration(token, kidId)`** in `lib/api.ts`.
- **"🚀 Acceleration plan"** card — lists each skipped skill (EN + BN title) with
  the reason label (EN/বাংলা via `ACCEL_REASONS` country-pack map) and the
  "Band N → M" jump chip. Fetched in `refreshAll`'s per-kid payload → works
  offline (already-loaded state).

### i18n
- Every new string is EN + BN. `ACCEL_REASONS` and the kid's skip strings are
  config maps (the #131 country-pack seam) — a new locale = new keys, no
  rewrites.
