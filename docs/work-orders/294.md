# #294 — Streak-freeze token system

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

One busy day breaks a streak, which feels bad for a kid who's been coming
back every day. Acceptance: **earn/spend flow** · **streak logic respects
it** · **offline**.

## Fix

A **🧊 streak-freeze token** that protects the streak against exactly ONE
missed day — earned on the day-7 tile of the login calendar (#281).

- **Earn** (`store.ts`, `novaClaimCalendar`) — the day-7 tile of the 7-day
  cycle also grants +1 freeze token (on top of its 🪙10). Claiming is
  once-per-day, so it's a genuine weekly reward.
- **Spend** (`store.ts`, `novaCompleteSession`) — streak logic is now
  gap-aware: `gap = days between lastDay and today`. On a new day:
  - `gap ≤ 1` → normal chain growth (`streak + 1`);
  - `gap === 2` (exactly one missed day) with a token → **chain survives**
    (`streak + 1`) and the token is spent;
  - `gap ≥ 3` → gentle restart (no token wasted on an unsalvageable gap).
  Brand-new kids (`lastDay === ""`) start fresh.
- **UI** (`App.tsx`) — a `🧊 N` pill in the login-calendar header shows the
  token balance; the calendar claim handler celebrates when a token is
  earned; the session-complete handler celebrates when a token saved the
  streak (spoken, in the app's language).
- **i18n** — 3 `Strings` entries EN + BN (`freezePill/EarnedSpeak/
  SpentSpeak`), Bangla digits via `bnNum`.
- **Offline** — local store only; coins/stats sync as before via #9.
