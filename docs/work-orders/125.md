# #125 — Auto-rollback if post-deploy check fails

**Status:** ✅ shipped 2026-08-13 — merged (#422); rides the next patch release as housekeeping.

## Problem

A bad deploy's post-deploy smoke failure only printed a rollback *hint* — the
box stayed on the broken build until someone manually intervened. The 0.26.14
smoke even hit a **false negative** (Cloudflare edge lag) that would have made
a naive auto-rollback destroy a perfectly good release.

## Fix

Version-tagged images + an origin-aware rollback:

- **`docker-compose.prod.yml`** — web/api services get
  `image: numberverse-demo-{web,api}:${NV_VERSION:-latest}`. Deploys build a
  version-tagged image; the previous version's image stays on the box.
- **`deploy.sh`** — passes `NV_VERSION` through to the box build (standalone
  deploy without `NV_VERSION` keeps building `:latest`).
- **`rollback.sh`** — restarts web+api from the previous version's image with
  `--no-build` (instant, no rebuild), then re-verifies the live stamp.
- **`release.sh`** — captures `PREV_TAG` before tagging; on smoke failure it
  first probes the **origin** (`http://192.168.0.104:8080`, bypassing
  Cloudflare):
  - origin serves the new version → **edge-cache lag** → wait up to 90s for
    the edge, do NOT roll back (a rollback would break a good deploy).
  - origin broken → genuine fault → `rollback.sh $PREV_TAG`.
- **`docs/RELEASING.md`** — Rollback section documenting both paths.
- Current `0.26.14` images backfilled with version tags on the box, so the
  first rollback target already exists.

## Files
- `infra/deploy/docker-compose.prod.yml` — `image:` tags
- `infra/deploy/scripts/deploy.sh` — NV_VERSION passthrough
- `infra/deploy/scripts/rollback.sh` — NEW rollback script
- `infra/deploy/scripts/release.sh` — PREV_TAG + origin-diagnostic rollback
- `docs/RELEASING.md` — rollback docs

## Verification
- `docker compose config` — `NV_VERSION=0.26.15` → `:0.26.15` images; default → `:latest` ✓
- `bash -n` on all three scripts ✓
- Box: `numberverse-demo-{web,api}:0.26.14` + `:latest` both present ✓
- Live rollback drill deliberately NOT run (would disrupt the running site).
