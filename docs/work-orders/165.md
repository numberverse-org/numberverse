# Work Order — #165: Bangla compound building (যোগে যোগে শব্দ)

**Status:** ✅ Merged via PR #492

## Problem
Band 2 has sentence/word-pair games but no word-formation mechanic. Kids need
to see that two small Bangla words can *join* to make one new word
(যোগে যোগে শব্দ) — a core NCTB vocabulary-building skill.

## Fix
New `CompoundScene` (`apps/kid/src/game/CompoundScene.ts`), band 2, scene key
`Compound`, skill `bn-compounds` (c2-bangla-8), game `game-compounds`
(difficultyLevels `[2,2,2,3,3,3]` = distractor count per tile bank).

**Mechanic — tap both parts:**
- A compound's emoji clue is shown big (🌹). The kid taps the TWO small words
  that join to make it (গোলাপ then ফুল).
- Each correct part snaps into its slot and is spoken aloud.
- When both land, the fused word pops in (গোলাপফুল), fires correctCelebrate
  fireworks, and the NEW word is spoken aloud (`speak(word, {lang:"bn"})`).
- Wrong words are retired (killOption); the second part tapped before the
  first is coached (keepOnWrong) with a bilingual "tap the FIRST word first" nudge.
- Distractors come from other compounds' parts, never the target's own parts.

**Data:** 18 everyday fused compounds (≥ 15 required), each `{a, b, word, e}`
with `word === a + b` literal concatenation (no sandhi), e.g. গোলাপ+ফুল,
মধু+মাছি, দুধ+ভাত, সকাল+সন্ধ্যা. First 6 = easy pool for levels 0-1.
