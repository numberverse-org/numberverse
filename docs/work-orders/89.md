From the ledger, show the missed questions per skill so re-teaching is transparent.

## Design notes
- Wrong-tap stories (via `hintWrong` → `wrongLedger.record(correct, wrong)`) are the only ones carrying exact answer values — that's fine: they ARE the granular "missed questions" a parent wants (scored-round misses still show game + diagnosis).
- Answer values follow the existing number-only rule (`typeof === "number"`), matching the fingerprintable math answers.
