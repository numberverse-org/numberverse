## Goal
A filterable search over a kid's stories (by skill, error kind, action).

## Done when
- [x] Filters
- [x] Counts shown

## What shipped
- **API filters**: GET `/kids/{kid_id}/stories` now accepts `skill_id`,
  `error_kind`, `action`, `misconception_code` (all optional, combinable).
- **Counts**: GET `/kids/{kid_id}/stories/stats` → `{total, by_skill,
  by_error_kind, by_misconception}` for surfacing recurring trouble.
- **Kid client**: `fetchStories(kidId, filters)` (server search),
  `fetchStoryStats(kidId)` (counts), `filterLocalStories(filters)` — the
  same filters against the store's local stories, fully offline.
- Reuses the durable-outbox identity mapping (local kid id → server id).
