# #121 — CI: post-deploy smoke test (stamp + tokens)

**Status:** ✅ released in 0.26.14 (2026-08-13)

## Problem

After a release deploy, nobody asserted the new build was actually live — a
stale container or a failed docker build would leave the OLD stamp serving
while the pipeline printed "✅ shipped".

## Fix

New **step 6/7 — Smoke test** in `infra/deploy/scripts/release.sh`:

- After deploy, curl `https://kids.munna-khan.xyz/`, extract the hashed
  `assets/index-*.js` from the live HTML, and assert that bundle carries this
  release's `$VERSION`.
- Retries 5× with 10s waits (docker takes a few seconds to warm up).
- On failure: prints a loud ✖ with a rollback hint (the box still runs the
  previous image) and **exits 1** — the release is NOT marked shipped.
