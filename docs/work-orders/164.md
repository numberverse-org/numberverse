# Work Order #164 — Bangla: punctuation placement (যতি চিহ্ন)

**Status:** ✅ Merged via PR #491

## Problem
Band-3 writers know words but not how sentences END. Bangla has its own
punctuation (দাঁড়ি ।, প্রশ্ন ?, বিস্ময় !) and no game taught where they go.

## Fix
New `PunctScene` (key `Punct`, skill `bn-punctuation`, game `game-punct`,
band 3):

- **22 sentences** (done-when: 20+): 8 statements (।), 7 questions (?), 7
  exclamations (!) — all everyday kid sentences, displayed WITHOUT their end
  punctuation with a golden slot box where the mark belongs.
- **Punctuation tile tap:** the kid taps the right tile (। ? ! ,) and it SNAPS
  into the slot with a Back.easeOut pop. "," only ever appears as a wrong tile
  (sentences never end with commas).
- **Reads the difference aloud:** on correct, the full sentence is spoken with
  its real punctuation, so the kid HEARS how ? and ! change the voice. Wrong
  tiles are retired with a sentence-type hint ("This asks a question — tap ?").
- **Difficulty ladder** `[2,2,3,3,4,4]` = punctuation tiles on screen
  (2 → 3 → 4). 5 questions per round, 3 rounds per level.
