# Work Order — #175: English R-controlled vowels (ar er ir or ur)

**Status:** ✅ Merged via PR #___

## Problem
Band 2 English needed the bossy-R phonics layer: the 5 R-controlled vowels (ar,
er, ir, or, ur) that change how a vowel sounds — a classic decode hurdle before
fluent reading.

## Fix
New `RControlledScene` (`apps/kid/src/game/RControlledScene.ts`), band 2, scene
key `RControlled`, skill `en-rcontrolled` (c2-english-4), game `game-rcontrolled`
(difficultyLevels `[3,3,3,4,4,4]` = option count).

**Mechanic — hear + pick spelling (done-when):**
- 25 words in **5 word families per vowel** (ar: car/star/jar/farm/bark · er:
  her/fern/tiger/river/letter · ir: bird/girl/shirt/first/stir · or:
  corn/fork/storm/horse/horn · ur: fur/turn/burn/nurse/purse), each with a
  picture emoji.
- The word is SPOKEN (English 🔊 with replay); the kid taps the correct spelling
  among 3-4 plausible bossy-R misspellings — `car` vs `cur`/`cer`/`cor`/`cir`
  generated by swapping the family vowel. Wrong taps retire that spelling and
  re-speak the word so the kid re-listens. Option count 3→4 across 6 tiers.
