# #356 — Onboarding tour for first play

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

A brand-new kid lands on home with no idea where to tap. Acceptance:
**3-5 steps** · **skippable** · **i18n clean**.

## Fix

A friendly 👋 **coach-Nova tour** — 4 steps that teach the core loop the first
time a kid reaches home, then never shows again on the device.

- **Steps** — 1) greet + the big PLAY button · 2) the learning path (more play
  → more worlds) · 3) Nova, the pet that grows as they learn · 4) the folded
  "More" menu (cards, badges, garden, fun voices).
- **Skippable** — a Skip button on every step AND tapping the dim closes it;
  skipping never marks it done, so a later session can still finish it. The
  final step's "Let's go!" marks `nv_tour_done` (once per device).
- **Locale-packed** (#131) — 12 `Strings` entries EN + BN; the step list is
  emoji + string keys only, so a new country is config, not a rewrite.
- **Gentle, never blocks** — dim overlay + bob-animated emoji; reduced-motion
  and offline are respected (pure DOM + localStorage).

## Files
- `apps/kid/src/App.tsx` — `TOUR_STEPS`, `tourStep` state + auto-open effect on
  first home, `closeTour`, tour card overlay, Strings EN+BN
- `apps/kid/src/styles.css` — `.tour-*` overlay/card/dots
