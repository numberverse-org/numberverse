# #292 — Nova reaction pack v2

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Nova reacts in her room, but never DURING learning. Acceptance: **8+ new
reactions** · **ties to events** · **offline**.

## Fix

A floating **Nova face bubble** that appears during play on win streaks,
setbacks and reteach moments — a DOM overlay, so it works over EVERY game
scene with zero Phaser changes.

- **10 new reactions** (locale-packed EN/BN in the `NOVA_REACTIONS` config):
  - `cheer` 🎉 combo 3 · `amaze` 🌟 combo 5 · `superstar` ⭐ combo 7 ·
    `streak` 🔥 session on-fire
  - `oops` 🤔 2 wrongs in a row · `gentle` 💛 3+ wrongs ·
    `setback` 😮 a miss right after a 3+ streak
  - `reteach` 🎯 when a step flips into its remediation re-run ·
    `master` 🏆 skill mastered · `quest` 🎁 quest complete
- **Exactly one per round** — a priority chain picks the biggest moment
  (master > quest > wrong-streak > correct-streak > setback), so reactions
  never stack or spam.
- **Gentle speak** — streak/setback/reteach lines are spoken aloud; `master`
  and `quest` are face-only because those rounds already have their own spoken
  cheer (no speech collisions).
- **Throttled** (~900ms) + auto-clears after ~2.6s; bubble pops + bobs with a
  CSS animation.
- **Offline** — reads the local session events only.
