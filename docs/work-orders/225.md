# Work Order #225 — Math: skip-counting by 3s & 4s

**Status:** DONE · **PR:** #552 · **Branch:** feat/225-skip-counting · **Merge:** main

## Problem
Band-2/3 math gap: learners count by 1s, 2s, 5s, 10s but not 3s & 4s. Issue
asks for a pattern game continuing +3 and +4 sequences on a number line, tap
the next, i18n clean.

## Fix
New `SkipCountScene` — "Skip count!": a +3/+4 sequence with green dots on a
number line and a pulsing "?" at the next position; the kid taps the next
number from 3 options.

- **Number-line visuals** — Graphics-drawn line with integer ticks, green dots
  at reached terms (labelled), orange dot + pulsing "?" at the blank position.
- **Tap the next** — "0 · 3 · 6 · ___" shown large; correct tap fills the
  blank, speaks the full sequence "0, 3, 6, 9", and bursts stars.
- **Off-by-one/off-by-two distractors** reward true skip-counting (a +2 or +4
  tap never scores); options always include the correct number exactly once
  (300k-question sim: 0 bad options, 0 negative, 0 short).
- **Ladder** — terms revealed ramp [2,3,3,4,4,5], start ranges ramp
  [0–6, 0–12, 0–12, 0–24, 0–24, 0–48]; step randomly 3 or 4, both mixed.
- 4 questions per round, `ROUNDS_TO_FINISH = 3`, bg "sunset".
