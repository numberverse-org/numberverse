# Work Order 205 — Science: plant life cycle (seed→sprout→plant→flower→fruit)

**Issue:** #205
**Status:** DONE (PR #532)

## Problem
Band-1/2 kids see plants everywhere but rarely stop to think "how did that
apple get here?". Ordering the plant life cycle turns a static fact into a
story — and a plant that visibly GROWS on every correct tap makes the sequence
sticky.

## Fix
New `PlantLifeScene` — order the plant life cycle:
- **5 stages** (4–5 as required): seed 🫘 → sprout 🌱 → plant 🌿 → flower 🌸 →
  fruit 🍎. Lvl 1–2 sequence seed→flower (4 stages), lvl 3+ the full 5.
- **Grow animation:** a terracotta pot is drawn under the big stage emoji; each
  correct tap springs the next stage out of the pot (Back.easeOut pop) with
  soil particles flying up. A timeline strip above fills left→right as the
  cycle completes.
- **Ordering with feedback:** shuffled stage cards (emoji-only, pre-reader
  friendly); wrong tap shakes red + floats "tap the {expected}"; correct tap
  turns the card green/disabled and lights its timeline slot.
- **Speaks** each stage name ("sprout!" / "চারা!").

Wired as skill `en-plant-life` (band 2 science, c2-science-7, class 2), game
`game-plantlife`, scene key `PlantLife`, bg "candy". i18n: 11 new lp* keys
(EN + BN), Bangla stage names for the BN locale.
