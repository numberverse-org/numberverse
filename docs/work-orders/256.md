# #256 — Parent: goal-setting screen (minutes/rounds per day)

**Status:** ✅ Shipped (PR #570)
**Priority:** low · parent-facing

## Goal
Parents set a gentle daily goal per kid; Nova nudges toward it without pressure.

## Done when
- [x] Goal per kid — `KidSettings.goal_min` (minutes/day), parent portal "🎯 Daily goal" input in the per-kid settings card
- [x] Nudge at goal — kid app home shows a goal progress line (nudges toward it) + a once-per-day dismissible Nova celebration when reached
- [x] Respects caps — the server clamps `goal_min` to the day's cap (flat `daily_limit_min`, else the highest weekday cap) at write time, so a goal can never exceed the hard limit

## Notes
- Goal minutes use the same `todayMinutes()` tracker as the daily cap (sum of scored-round response ms + session elapsed), so "minutes" matches what the parent portal reports.
- Nudge is suppressed the moment the hard cap is also reached (they never fight), and once-per-day via the nudged flag.
- Parent portal settings card is inline-English like the rest of that section (no new config map needed for one input); the kid-facing strings are EN+বাংলা.
