# Work Order #223 — English: irregular past tense

**Status:** DONE · **PR:** #550 · **Branch:** feat/223-irregular-past-tense · **Merge:** main

## Problem
Band-3 grammar gap: kids learn regular -ed past but not irregular verbs. Issue
asks for 15+ verbs, sentence context, i18n clean.

## Fix
New `PastTenseScene` — "Past time!": shows the present form ("Today I go 🚶")
+ a past-time sentence with a blank ("Yesterday I ___ to school."); the kid
picks the irregular past tense from 3 options.

- **16 irregular verbs** — go→went, see→saw, eat→ate, take→took, make→made,
  come→came, give→gave, run→ran, sing→sang, swim→swam, drink→drank,
  write→wrote, read→read (no spelling change), buy→bought, think→thought,
  sleep→slept. Each with an emoji hint.
- **Sentence context** — every verb has a first-person past-time sentence
  (`ivS1-16`, EN+BN) rendered with a `___` blank; a correct tap fills the
  blank and speaks the full sentence.
- **Shuffle-bag + round-level dedupe** — bag-refill boundary never repeats a
  verb shown in the round (300k-round sim: 0 dups).
- **3 string-distinct options** — correct past appears exactly once.
- Ladder `[4,4,6,6,8,8]`, `ROUNDS_TO_FINISH = 3`, bg "sunset".
