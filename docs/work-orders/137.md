# #137 — Seasonal events decor (Eid, Pohela Boishakh…)

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

The journey path changes with the real season, but specific festivals (Eid,
Pohela Boishakh, Christmas, Diwali…) had no in-app presence.

## Fix — festivals as CONFIG in the locale pack (#131-aligned)

The user directive: "like Bengali, later we may use any other language country
based" → festivals are **country-based config**, not code:

- **`LocalePack.festivals`** (packages/core/src/locale.ts): a list of
  `FestivalEvent` — key, emoji, and inclusive windows. Fixed feasts use
  `MM-DD` (any year); lunar feasts (Eid, Ramadan) move ~11 days/year so they
  carry one `YYYY-MM-DD` window per year as *data*.
  - bn: Pohela Boishakh (fixed Apr) + Eid al-Fitr + Eid al-Adha (lunar, 2026–2030)
  - en: Christmas · ar: Ramadan + Eid · hi: Diwali + Holi (planned scaffolds)
- **`currentFestival(code, date?)`** — pure function, falls back to en for
  unknown codes (same contract as every other locale helper).
- **Kid app** — a festival banner on the home screen (glow animation) while a
  window is active; label localized via `fest_*` STR keys (EN + BN + planned
  packs). Off-season renders nothing.
- **CI gate** — `scripts/test-locale.mjs` grew 9 festival checks (27 total).
