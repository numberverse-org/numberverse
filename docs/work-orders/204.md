# Work Order 204 — Science: animals — features & movement (sort by fly/swim/crawl/walk)

**Issue:** #204
**Status:** DONE (PR #531)

## Problem
Band-1/2 kids meet animals before they meet anatomy — the FIRST feature they
can reliably tell apart is how an animal moves. Sorting animals into movement
bins turns that instinct ("fish swim, snake crawls") into a real
classification, and drag-into-bin is the natural gesture for sorting.

## Fix
New `AnimalsMoveScene` — sort 24 animals by movement:
- **24 animals** (≥20 as required), 6 per movement, each with ONE clear way of
  moving: fly (bird, butterfly, bee, eagle, ladybug, bat) · swim (fish,
  dolphin, shark, octopus, crocodile, seal) · crawl (snake, snail, ant,
  caterpillar, spider, lizard) · walk (elephant, cow, horse, chicken, giraffe,
  rabbit).
- **Sort with feedback:** the kid drags the big animal emoji into one of 4
  bins (Fly 🕊️ / Swim 🌊 / Crawl 🪱 / Walk 👣). Correct → the animal lands in
  the bin with a green ring + pop + win. Wrong → the bin shakes red, the RIGHT
  bin flashes green as a hint, and the animal flies back to its perch to retry
  (never punished, always shown the answer).
- **Speaks names:** the question is spoken with the animal's name ("How does
  the {animal} move?"), and a correct drop speaks the full fact — "The bee
  flies" / "মৌমাছি উড়ে" (anSpeak, verb-conjugated per movement).
- **Tiered pool:** lvl 1–2 = 10 famous animals, lvl 3–4 = 18, lvl 5–6 = all 24;
  round size 3→5 animals. Every pool keeps all four movements.

Wired as skill `en-animals-move` (band 2 science, c2-science-6, class 2), game
`game-animalsmove`, scene key `AnimalsMove`, bg "forest". i18n: 37 new keys
(an*, incl. 24 animal names) EN + BN — all locale keys, so a new
country/language pack is a dict addition only.
