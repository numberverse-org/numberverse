# Work Order — #181: English question words (who what where when why)

**Status:** ✅ Merged via PR #___

## Problem
Band 2 English grammar needed question words — the little words that open a
question (who, what, where, when, why, how, whose). A picture context + a
sentence with a blank is the natural way to make "which word fits?" concrete
for a kid.

## Fix
New `QuestionWordsScene` (`apps/kid/src/game/QuestionWordsScene.ts`), band 2,
scene key `QuestionWords`, skill `en-qwords` (c2-english-7), game
`game-qwords` (difficultyLevels `[3,3,4,4,4,4]` — 3 options early, 4 later).

**Mechanic — tap the word that fills the blank (done-when):**
- **22 question slots (done-when, ≥20):** 🎂 "___ is your birthday?" → when,
  👧 → who, 🍎 → what, 🏠 → where, 🎉 → why, 🚌 → how, 📚 "___ book is this?" →
  whose … all 7 question words covered (who 4, what 4, where 4, when 3, whose 3,
  why 2, how 2). Picture-context emoji + `questionPanel` sentence with a `___`
  blank.
- The sentence is SPOKEN with the blank paused; a 🔊 replay re-speaks it. A
  correct tap fills the blank, re-reads the whole question aloud, pops 🎉 +
  "Great question!". Wrong taps retire via `hintWrong` (dims the tile).
