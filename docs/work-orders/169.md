# Work Order — #169: Bangla numbers 1-100 word↔digit (সংখ্যা শব্দ)

**Status:** ✅ Merged via PR #496

## Problem
bn-numbers (band 1) teaches ০-৯ glyphs. Reading the NUMBER WORDS (এক, বিশ,
একুশ…) and mapping them to digits 1-100 was missing — a core reading/quant
bridge for band 2.

## Fix
New `NumberWordsScene` (`apps/kid/src/game/NumberWordsScene.ts`), band 2, scene
key `NumberWords`, skill `bn-number-words` (c2-bangla-10), game
`game-numberwords` (difficultyLevels `[2,3,3,4,4,5]` = option count).

**Mechanic — word↔digit match, staged:**
- Rounds alternate directions: word→digit (একুশ → tap 21) and digit→word
  (21 → tap একুশ).
- Stages per level: 1-10 → 1-20 → 11-50 → 21-100 → 1-100 → 1-100
  (done-when "1-100 in stages").
- Distractors are NEAR-NEIGHBORS (n±1, ±2, ±5, ±10, +20) filtered to the stage
  range — a real discrimination, never a far wild-card — topped up in-range.
- Speak every number: word→digit auto-speaks the word up front + 🔊 replay;
  every correct answer re-speaks the number (done-when "speaks every number").

**Data:** full unique Bangla word table 1-100 (script-verified, 100/100
non-empty, 0 duplicates) — including the irregular teens (এগারো…উনিশ) and the
irregular unit-tens compounds (একুশ, বাহাত্তর, নিরানব্বই, একশো).
