# Work order #335 — Moni: per-skill error fingerprinting
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-335`

## Goal
Cluster repeated wrong answers into recognizable misconception codes automatically.

## Done when
- [x] Fingerprint detector
- [x] New codes logged
- [x] Feeds contrast drills

## What shipped
- **Fingerprint detector** (`packages/core/src/moni/fingerprint.ts`):
  `fingerprintAnswer(skillId, correct, wrong)` maps a wrong VALUE against the
  correct one into a recognizable misconception code — deterministic, pure,
  numeric-only (language values never match, so no false positives):
  - `overcount-1` / `undercount-1` (one off)
  - `off-by-ten` / `off-by-hundred` (place-value mix-ups)
  - `double` / `half`
  - `reversal` (6↔9, 2↔5, 8↔3 digit mirrors)
- **Wrong values now flow to Moni**: `hintWrong` passes the tapped value + the
  correct value through `wrongLedger.record(correct, wrong)` → the store.
- **New codes logged**: on the 2nd+ repeat of the same pattern, the specific
  code is recorded into Moni's misconception ledger (replacing the generic
  "repeated-error") and the Kotha story logs `misconceptionCode` +
  `fingerprint` + the raw wrong value in context.
- **Feeds contrast drills**: `diagnose()` now prefers the SPECIFIC
  misconception over the generic one, so the contrast-drill copy names the
  real pattern ("Counts one too many", not "repeats the same kind of mistake").
