# Work order #325 — Moni: misconception contrast drills
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-325`

## Goal
When Moni flags a misconception, generate a side-by-side contrast round targeting it.

## Done when
- [x] Contrast template
- [x] Ties to misconception code
- [x] Warm messaging

## What shipped
- **Contrast templates** (`apps/kid/src/App.tsx` — `CONTRAST_TEMPLATES`): a
  side-by-side quiz keyed by misconception CODE (`reversal`, `overcount-1`,
  `undercount-1`, `off-by-ten`, `double`, `half`). Each round shows two big
  options — the correct answer and the pattern's trap — around a warm prompt,
  with a gentle tip underneath. Only codes with a template get a drill, so a
  random guess never triggers one.
- **Ties to misconception code**: the template map is indexed by the exact
  `code` Moni fingerprints (the `Misconception.code` in the ledger). The
  home-screen trigger picks the most recent confirmed misconception that has a
  template and launches its drill; finishing it resolves THAT code in Moni's
  ledger via the new `moni.resolveMisconception` (core) + store action
  `moniResolveMisconception` — the specific pattern (and its generic
  `repeated-error` twin on the same skill) is cleared, other skills untouched.
- **Warm messaging**: every surface is kind and pressure-free — the trigger
  pill ("Moni spotted a pattern — fix it together! No pressure"), per-round
  praise ("Correct! You spotted the pattern! 🎉"), a soft nudge on a miss
  ("That's the trick! The answer is 34. Try again!") that re-asks the SAME
  round (never advances on a wrong pick), and a "Pattern beaten! 🏆"
  celebration. Fully localized EN + BN.
- **Never a wall**: Home/back is always available mid-drill; wrong picks just
  re-ask.
- **Offline**: templates + resolution are pure local (core function + Zustand
  store). No network.
