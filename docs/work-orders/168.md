# Work Order — #168: Bangla graded read-a-story (গল্প পড়ি)

**Status:** ✅ Merged via PR #495

## Problem
Band 3 has StoryReadScene (one who/what question per mini-story) but no true
READING experience: word-by-word audio so a kid can decode each word, then a
real comprehension check. #168 adds exactly that, graded across 3 stories.

## Fix
New `ReadStoryScene` (`apps/kid/src/game/ReadStoryScene.ts`), band 3, scene key
`ReadStory`, skill `bn-read-story` (c3-bangla-6), game `game-readstory`
(difficultyLevels `[3,3,3,4,4,4]` = quiz option count).

**Two-phase round (one per story, 3 rounds):**
- **READ** — the story renders as tappable WORD chips (measured + wrapped like
  RhymeTime). Tapping any word speaks it (word-by-word audio, punctuation
  stripped). 🔊 "Read it all" reads the whole story. "Done → Questions" advances.
- **QUIZ** — 3 comprehension questions with emoji answers. A correct tap reads
  the ANSWERING sentence aloud (comprehension reinforcement); wrong taps retire
  with a bilingual "re-read the story in your head" nudge + the question re-read.

**Grading:** story 1 (সকালের গল্প) shortest/known words → story 2 (ববি কুকুর)
mid → story 3 (বর্ষার দিন) longer/harder. Stories always play in order;
difficulty level gates quiz options 3 → 4.
