# #262 — Privacy: on-device data review for parents

**Status:** ✅ done (merged — issue CLOSED)

## Problem

The kid PWA keeps a rich localStorage payload (progress, outbox, stories,
identity) so it can run offline — but parents had no way to see what is stored
on a device, or clear it.

## Done-when (from the issue)

- [x] **Category list** — a new "🛡️ On-device data" section in the parent
      portal lists everything in this browser's `nv_*` keys, grouped into
      Learning progress / Device & kid identity / Parent account, with
      byte sizes and per-key human summaries (rounds, queued syncs, stories,
      kids mapped).
- [x] **Delete action** — per-category "Clear N KB" with confirm; localStorage
      removal is immediate.
- [x] **Works offline** — purely client-side reads/writes; zero network, zero
      API dependency.

## Files

- `apps/parent/app/OnDeviceData.tsx` — the review component (self-contained)
- `apps/parent/app/page.tsx` — imports + renders the section
- `apps/parent/app/globals.css` — `.danger-zone-right` layout rule

## Verification

- `pnpm --filter parent typecheck` ✓
- `pnpm --filter parent build` (static export) ✓ — `/` route ships with the section

## Notes

Clearing on-device data NEVER touches the server — server-side progress lives
in the parent's account (export / roster delete handle that). The kid app
re-provisions identity on next launch.

## Release

Feature — rides the next release.
