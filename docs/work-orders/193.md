# Work Order 193 — Math: 2-digit subtraction with borrowing (visual)

**Issue:** #193
**Status:** DONE (PR #___)

## Problem
Band 2 kids need the written method for borrowing taught visually — base-10
blocks, a step-by-step scaffold, and an explicit borrow animation (the twin of
the #192 carry game).

## Fix
New `SubBorrowScene` — written-method box + base-10 blocks:
- **Step-by-step scaffolding:** Step 1 "Borrow & subtract the ones" (ones column
  highlighted) — the minuend blocks show tM bars + oM cubes; kid picks the ones
  digit. Step 2 "Subtract the tens" — kid picks the tens digit; the tens
  subtraction "4 − 2 = 2" floats up and the full answer is spoken.
- **Borrow animation:** every question forces a borrow (ones of subtrahend >
  ones of minuend). On the correct ones digit, a green bar lifts off the tens
  column, flies to the ones column, and BREAKS into 10 cubes that bounce into
  place; the written-method digits update 52 → 4|12 (borrowed ones turn green),
  an orange "Borrow 1!" chip pops, and it is spoken.
- **Generation:** minuend tens 3–8 (≥3 so tens result ≥ 1, answers stay
  2-digit), subtrahend tens ≤ minuend−2, ones always force a borrow.
- Wrong answer → shake + dim + green reveal + "12 − 7 = 5" hint.

Wired as skill `en-subborrow` (band 2 math, c2-math-11, class 2), game
`game-subborrow`, scene key `SubBorrow`, bg "space". i18n: 7 new bo* keys
(EN + BN) — note sb* was taken by the sentence-builder, hence bo*. Bangla
digits for the BN locale.
