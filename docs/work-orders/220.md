# #220 — English: digraph review challenge (sh ch th wh ph)

**Status:** DONE · **PR:** #547 · **Branch:** feat/220-digraphs

## Problem
A band-1/2 phonics review game consolidating digraphs with speed rounds.
Requirement: "All 5 digraphs · Hear + pick · Speed tier · i18n clean."

## Fix
New `DigraphsScene` ("Digraph match", skill `en-digraphs`, c2-english-12,
class 2):
- **All 5 digraphs** sh / ch / th / wh / ph, each with **5 kid words** (25
  total: ship 🚢, shell 🐚, chair 🪑, cheese 🧀, thumb 👍, three 3️⃣, whale 🐋,
  wheel 🛞, phone 📱, dolphin 🐬, elephant 🐘…).
- **Hear + pick**: the word is spoken aloud with the digraph missing shown as
  "__ip" under a picture; the kid taps the digraph button that makes the word.
  Correct → word fills in + is spoken + star burst.
- **Every round shows one word per digraph** — all 5 guaranteed every round.
- **Speed tier**: a shrinking timer bar ramps down per level
  (10s → 9s → 8s → 7s → 6s → 5s). Timeout → gentle "Faster!" (counted as a
  miss, never punished).
- Level ladder: [10000, 9000, 8000, 7000, 6000, 5000] ms/pick.
