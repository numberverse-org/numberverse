# Work order #340 — Kotha: weekly story digest export
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-340`

## Goal
A parent-exportable digest of the week's stories (text, no PII beyond kid name).

## Done when
- [x] Digest file
- [x] Weekly cadence
- [x] No cloud

## What shipped
- **Parent panel**: a "📄 Weekly digest" button next to Share progress exports
  the last **7 days** of Kotha stories for that kid as a plain-text `.txt` file.
- **Content**: header (kid name + week range), a stats line (N moments · X
  solved · Y tricky), then one block per story — date, skill title, game,
  outcome (✓ solved / ⚠ misses), Moni misconception when present, difficulty.
  No PII beyond the kid's name.
- **No cloud**: reads the store's own story outbox (`useKidStore.stories`,
  filtered by local kid id + ts), builds the text in-browser, downloads via
  Blob + object URL. Works fully offline.
- i18n: all 8 digest strings in EN + BN.
