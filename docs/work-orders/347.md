# #347 — PWA: iOS home-screen polish

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Safari ignores the web manifest, so an iOS install lives or dies on the
`apple-*` meta + icon + startup-image tags. Icon and meta were already in
place; the splash was the gap. Acceptance: **apple-touch icons** · **splash
sizes** · **test on device**.

## Fix

Complete the iOS home-screen fidelity:

- **Apple-touch icons** — already shipped (`/apple-touch-icon.png`, 180×180 —
  the exact size iOS wants; verified with `sips`).
- **Splash sizes** — generated 12 portrait `apple-touch-startup-image` PNGs
  (solid `#0b2545` + centered owl) covering every modern iPhone/iPad
  resolution: 1290×2796, 1170×2532, 1284×2778, 1179×2556, 1125×2436, 828×1792,
  750×1334, 1242×2208, 1536×2048, 1620×2160, 1668×2388, 2048×2732. Each is
  wired with the exact `media="(device-width) and (device-height) and
  (-webkit-device-pixel-ratio)"` query so only the matching device downloads
  its image. Older iOS ignores startup-image entirely and auto-splashes from
  the icon + theme color — no regression possible.
- **Meta** — `apple-mobile-web-app-capable`, `black-translucent` status bar,
  `apple-mobile-web-app-title` all verified already present.
- App is portrait-locked (manifest `orientation: portrait`), so portrait-only
  splashes are correct.
