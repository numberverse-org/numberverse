# Work Order — #183: English compound words (rain+bow=rainbow)

**Status:** ✅ Merged via PR #___

## Problem
Band 2 English vocabulary needed the "two words make one" concept — a compound
word is two halves joined together (rain + bow = rainbow). The most tactile way
is to let the kid tap the two halves in order and see them fuse.

## Fix
New `CompoundEnScene` (`apps/kid/src/game/CompoundEnScene.ts`), band 2, scene
key `CompoundEn`, skill `en-compounds` (c2-english-9), game
`game-compounds-en` (difficultyLevels `[3,3,4,4,4,4]` — 3 halves per side early,
4 later).

**Mechanic — tap BOTH halves (done-when):**
- **16 compounds (done-when, ≥15):** rainbow 🌈, sunflower 🌻, butterfly 🦋,
  starfish ⭐, cupcake 🧁, toothbrush 🪥, basketball 🏀, football ⚽, snowman ⛄,
  pancake 🥞, watermelon 🍉, pineapple 🍍, jellyfish 🪼, honeybee 🐝, fireman 🧑‍🚒,
  bookshelf 📚. 28 distinct halves, no full word repeats.
- A picture + spoken word; `[ ? ] + [ ? ] = ?` slots. The kid taps the FIRST
  half (wrong tap → `hintWrong` dims it), then the SECOND half. Correct halves
  fill the slots, the used tiles dim, and the full word is shown + spoken
  ("rain + bow = rainbow"). Wrong-order taps teach that halves come in a fixed
  order (butter + fly, not fly + butter).
- Decoy pools are de-duplicated across compounds (ball, cake, man, fish repeat),
  so a bank never shows a half twice and the answer appears exactly once.
