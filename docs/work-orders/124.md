# #124 — Structured error logging (no analytics)

**Status:** 🔜 in progress (PR open)

## Problem

The API only logged to stderr (uvicorn console). A stack-trace investigation
meant scraping container logs; there was no durable, local, queryable record
of warnings/errors, and no rotation.

## Fix

New `apps/api/app/errorlog.py` + tests, wired into `main.py`:

- **Error log writer** — every `WARNING`+ record from any `numberverse.*`
  logger is appended to `data/error.log` as **one JSON object per line**
  (`ts`, `level`, `logger`, `msg`, `exc`). Info/debug never lands on disk.
- **Rotation** — `RotatingFileHandler`: 1 MB × 3 backups.
- **Privacy review** — the file handler carries the same `ScrubFilter` as
  #266, AND the JSON formatter re-redacts the *rendered* traceback (base
  `Formatter.format` computes `exc_text` from `exc_info` *after* filters run,
  so a filter alone would let PII-shaped traceback lines through). Zero
  analytics — nothing leaves the box.
- Idempotent `install()` (uvicorn reload / tests never double-attach); a
  broken path degrades to a loud stderr warning, never a crash.
- `*.log` is already gitignored — the artifact can never be committed.

## Files
- `apps/api/app/errorlog.py` — new module (writer + rotation + redaction)
- `apps/api/app/main.py` — calls `install_errorlog()` at startup
- `apps/api/tests/test_errorlog.py` — 13 self-contained checks (write/scrub/
  no-info/traceback-redaction/rotation/idempotence)
- `.github/workflows/ci.yml` — api job runs the new test
- `docs/RELEASING.md` — api gate description updated

## Verification
- `python3 apps/api/tests/test_errorlog.py` → "✓ all errorlog checks passed"
  (13/13): WARNING+ lands as JSON, INFO doesn't, phone/email/IP redacted in
  both msg and rendered traceback, .1 backup appears after rotation, handler
  attaches once.
