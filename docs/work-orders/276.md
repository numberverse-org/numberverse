# #276 — Skill-tree map per land

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Each land's detail screen shows a flat list — no visual sense of the path.
Acceptance: **Per-land tree** · **mastered nodes glow** · **tap to jump**.

## Fix

A **🌳 Skill Tree** replaces the flat skill list on the world-detail screen:
every skill in the land is a leaf branching off a central trunk (alternating
left/right), so the kid SEES the journey through the land at a glance.

- **Per-land tree** — one trunk per land, one leaf per playable skill, in
  journey order (same linear unlock as the home path).
- **Mastered nodes glow** — a mastered leaf is green-glowing with a ✓ and a
  gold progress bar; the next lesson pulses amber with a "Next" badge.
- **Tap to jump** — every leaf is a button that starts that skill directly
  (same behaviour as the old list, now visual).
- **Locale-packed** — 2 new `Strings` entries EN + BN (`treeTitle`/`treeHint`),
  leaf titles read the locale `titleBn` (#131). Offline, local mastery only.

## Files
- `apps/kid/src/App.tsx` — skill-tree JSX in `worlddetail` (replaces the flat
  list), Strings EN + BN
- `apps/kid/src/styles.css` — `.tree-wrap`/`.tree-trunk`/`.tree-row`/`.tree-node`
  + mastered glow + `treePulse` for the next leaf
