# #271 — Guardrail: dependency license audit gate

**Status:** in progress (2026-08-13)

## Problem

A contributor could `pnpm add` a package under a copy-left or unlicensed
license and ship it silently. There was no gate reviewing bundled dependency
licenses.

## Fix

New `scripts/license-audit.mjs` + a CI job:

- Parses `pnpm licenses list --json` and fails if ANY bundled dependency's
  license is outside the allowlist (`scripts/license-audit.mjs` → `ALLOWED`:
  MIT, ISC, Apache-2.0, BSD/2/3-Clause, 0BSD, CC0-1.0, CC-BY-4.0,
  BlueOak-1.0.0, MPL-2.0 — plus compound `(A OR B)` where all members are
  allowed). Handles SPDX `(A OR B)` compounds.
- `docs/LICENSES.md` — the policy table + "adding a dependency" procedure.
- `.github/workflows/ci.yml` → new `license-audit` job (parallel, no core-dep)
  runs on every PR.
- Current tree: 445 deps, all allowed.
