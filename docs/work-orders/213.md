# Work Order 213 — Social: our festivals — customs sort

**Issue:** #213
**Status:** DONE (PR #540)

## Problem
A band-2 civic game sorting actions/items for Pohela Boishakh and Eid. Kids
see both festivals but need to connect the customs to the right one.

## Fix
New `FestivalSortScene` — drag each custom into the matching festival bin:
- **2 festivals × 8 items (16 total):** Pohela Boishakh 🎉 (panta bhat 🍚,
  hilsa fish 🐟, alpana art 🎨, new year 🗓️, nakshi kantha 🧵, shobhajatra 🎭,
  basanti clothes 👕, boishakhi flowers 🌷) and Eid 🎊 (semai 🍜, new clothes
  👔, eidi 💵, sweets 🍬, eid card 💌, new shoes 👟, khichuri 🍛, henna 🌿).
- **Gentle, non-religious-adjacent:** every item is an everyday cultural
  custom — food, clothes, cards, art, henna. No prayers, no religious objects.
- **Drag-sort mechanics:** the kid drags each item card into the right bin;
  correct drops land with a pop + spoken "{item} for {festival}" and the item
  flies into the bin; wrong drops shake red and flash the right bin green.
- **Bangla+EN:** item and festival names localized (পান্তা ভাত/panta bhat,
  পহেলা বৈশাখ/Pohela Boishakh).
- Lvl 1–3 use the 8 easy customs (4 per festival), lvl 4+ all 16.

Wired as skill `bgs-festivals` (band 2 BGS, c2-bgs-3, class 2), game
`game-festivals`, scene key `FestivalSort`, bg "sunset". i18n: 23 new fc*
keys (EN + BN).
