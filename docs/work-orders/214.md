# #214 — Values: kindness & sharing scenarios

**Status:** DONE · **PR:** #541 · **Branch:** feat/214-kindness

## Problem
A band-1 values game where the kid chooses the *kind* response in everyday
situations. Requirement: "10+ scenarios · Celebrates kind choices · i18n clean."

## Fix
New `KindnessScene` ("Kind heart", skill `bgs-kindness`, c1-bgs-2, class 1):
- **12 everyday scenarios** (`kdSit1..12`) — friend forgot a crayon, friend
  falls and cries, one biscuit two friends, etc. Each shows an emoji + the
  situation (spoken in en/bn) and two buttons: a **green kind choice**
  (`kdGoodN`) and a **neutral unkind one** (`kdNotN`).
- **Celebrates kind choices**: kind tap → `pop` + `win` + a heart burst + a
  rotating praise (`kdPraise1..4`) that floats and is spoken aloud.
- **Never punishes** unkind taps: a gentle "Try the kind way" (`kdGentle`)
  + a soft pulse on the green button so the kid still *sees* the kind path.
- **Level ladder** [2,2,3,3,4,4] = scenarios per round; each round shuffles
  ALL 12 scenarios (shuffle-bag guarantee — every kid meets every situation).
- Difficulty ramps with level only (more scenarios per round).
