# Work Order 199 — Math: making change with ৳ notes

**Issue:** #199
**Status:** DONE (PR #___)

## Problem
Band 3 kids pay with ৳50/৳100 notes every day but often can't compute the
change or build an exact amount. They need note visuals + pay/change combos that
make the subtraction (৳50 − ৳32 = ৳18) concrete.

## Fix
New `MakeChangeScene` — two alternating questions:
- **CHANGE** — a big ৳50 or ৳100 note is shown with a price chip ("Costs ৳32");
  the kid computes the change and taps it from 4 cards (৳18). Correct → the
  spoken equation "৳50 minus ৳32 is ৳18" (chSpeak) + a green check. Distractors
  are other multiples of 5 in ৳0..৳pay.
- **MAKE** — "Tap notes to make ৳45": the kid taps notes off a tray
  [৳50, ৳20, ৳20, ৳10, ৳10, ৳5] (live ৳ total, green rings) then ✅ checks.
  Every multiple of 5 from ৳5 to ৳95 is buildable from the tray by construction.

**Note visuals:** real Bangladesh colours — ৳5 gold coin, ৳10/20/50/100 rounded
notes (৳50 purple, ৳100 red); Bangla digits for the BN locale.

Ranges: pay ৳50 (lvl 1–3), ৳50/৳100 (lvl 4+, includes exact-pay ৳0 change);
make targets ৳10–৳40 / ৳70 / ৳95 by level.

Wired as skill `en-makechange` (band 3 math, c3-math-11, class 3), game
`game-makechange`, scene key `MakeChange`, bg "sky". i18n: 9 new ch* keys
(EN + BN). Bangla digits.
