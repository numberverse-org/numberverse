# Work Order 206 — Science: weather & seasons sorting

**Issue:** #206
**Status:** DONE (PR #533)

## Problem
Band-1 kids live inside the weather every day (অত গরম, বৃষ্টি, ঠান্ডা) but the
connection "this clothing belongs to that season" is a mental map they build by
SORTING, not by telling. A drag-into-bin season sort makes the map physical.

## Fix
New `WeatherSeasonsScene` — sort clothes & activities into the 4 seasons:
- **4 seasons × 5 items** (20 items as required): Summer ☀️ (sunscreen,
  watermelon, t-shirt, sunglasses, beach umbrella) · Rainy 🌧️ (umbrella,
  raincoat, rain boots, rainbow, rain cloud) · Winter ❄️ (scarf, gloves,
  snowman, hot cocoa, wool socks) · Spring 🌸 (flower, kite, butterfly, chick,
  seedling).
- **Drag-into-bin with feedback:** wrong drop shakes red + flashes the right
  bin green, item returns to retry; correct drop lands with a green ring,
  pop + spoken "{item} for {season}" — "raincoat for rainy" / "বর্ষায়
  রেইনকোট".
- **Bangla + EN labels:** every item name, season name, prompt and float is a
  locale key — EN on en, BN on bn (the issue's Bangla+EN requirement).
- **Tiered pool:** lvl 1–2 = 9 famous items, lvl 3–4 = 16, lvl 5–6 = all 20;
  every pool keeps all four seasons.

Wired as skill `en-weather-seasons` (band 1 science, c1-science-2, class 1),
game `game-seasons`, scene key `WeatherSeasons`, bg "sky". i18n: 31 new ws*
keys (EN + BN).
