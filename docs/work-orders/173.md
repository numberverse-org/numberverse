# Work Order — #173: Bangla polite words social game (শিষ্টাচার)

**Status:** ✅ Merged via PR #___

## Problem
Band 1 needed a values/social skill: recognizing the polite reply (ধন্যবাদ,
দয়া করে, দুঃখিত) in everyday scenarios — the social-emotional foundation kids
need before they can use language to build relationships.

## Fix
New `PoliteScene` (`apps/kid/src/game/PoliteScene.ts`), band 1, scene key
`Polite`, skill `bn-polite-words` (c1-bangla-8), game `game-polite`
(difficultyLevels `[3,3,3,4,4,4]` = option count).

**Mechanic — scenario → tap the polite response (done-when):**
- 12 everyday scenario cards (👵 দিদিমা, 🎁 উপহার, 🚌 বাস, 🥛 ভাঙা গ্লাস …), each
  with a big emoji + the spoken question ("দিদিমা তোমাকে মিষ্টি দিলেন। তুমি কী
  বলবে?").
- The scenario reads itself aloud on arrival (Web Speech, bn); a 🔊 replay
  button re-reads it. The kid taps the polite word card (ধন্যবাদ / দয়া করে /
  দুঃখিত) that fits.
- Correct → the word pops bigger, is spoken aloud, win sound + correctCelebrate.
  Wrong → the tile is killed (dims/✕) and the scenario is re-spoken so the kid
  can hear and try again. 3 levels option counts 3→4, 6 tiers.
- Words are balanced 4/4/4 across the three politeness targets; distractors come
  from the OTHER polite words + neutral replies (না, এসো, দাও …).
