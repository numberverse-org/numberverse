# #405 — Access control: kids must never reach parent things + kid-only Settings

**Status:** ✅ review → merged → released

## Problem

The Settings page was still not good AND a kid could reach parent surfaces:
- Settings exposed the Parent Portal door, a guest sign-in/upgrade card, the
  parent-analytics button, and (signed-in) aggregate class insights.
- The parent panel (`screen === "parent"`) had **no session check** — a guest
  kid tapping "Parent analytics" got family summaries, per-kid stats, the
  wrong-answer ledger, MONI strictness controls, sign-out, and VoiceCheck.

## Fix

### Kid-facing Settings = kid controls only
- **Sound & voice** — music switch, voice status + test + neural voice picker +
  download progress + "reading is off" note.
- **Screen** — fullscreen switch, install button.
- **Language** — English / বাংলা two pills.
- **My learning** — syllabus + friendly sync line.
- **For parents** — one distinct gated zone at the bottom (dashed divider, gold
  tint). Tapping it calls `goParent()`.

### Parent area = grown-ups-only
- `goParent()`: signed-in parent → the panel; anyone else → the parent gate.
  Guest-skip always goes to the kid area, never the panel.
- Defense-in-depth: an effect bounces any non-session landing on `"parent"` to
  the gate (stale deep links, future regressions).
- Aggregate class-insights card moved into the (now gated) parent panel.
- Removed the now-unreachable guest portal-button + guest-upgrade card, plus the
  dead strings/CSS they used.

### Parent controls remain immutable in the kid screen
`tts_enabled=false` → the reading card shows "a parent turned reading off".
`music_enabled=false` → the music switch is disabled with an explanatory note.
A kid can never re-enable a parent's control from Settings.

## Files
- `apps/kid/src/App.tsx` — goParent + access-control effect, kid-only Settings
  rewrite, aggregate card moved to parent panel, guest surfaces removed, dead
  strings removed
- `apps/kid/src/styles.css` — ".For parents" zone, disabled-switch state,
  dead CSS removed
