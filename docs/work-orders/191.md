# Work Order 191 — Math: making ten strategy

**Issue:** #191
**Status:** DONE (PR #518)

## Problem
Band 1/2 kids need the "make ten" strategy (8+5 = 8+2+3 = 10+3) taught with
ten-frame visuals, bridging sums into the teens.

## Fix
New `MakeTenScene` — free-paced strategy game built on two ten-frames:
- **Ten-frame visuals:** the first frame shows the base addend (blue dots) and
  fills the remaining cells with the make-ten part (green dots) to compose 10;
  the leftover part of the second addend lands in a second frame (yellow dots).
- **Bridge to teens:** every generated question bridges past ten (sums 11–18).
  a ∈ 6–9, b ≥ 10−a+1 so make = 10−a is always ≥ 1 and leftover ≥ 1.
- **Strategy line:** "make ten: 8 + 2 = 10 · 10 + 3 = 13" is always visible.
- **Spoken confirmation:** correct tap speaks "Make ten: 8 plus 2 is ten, ten
  plus 3 is 13!" (Bangla for the BN locale).
- Wrong tap → shake + dim + green reveal of the answer (the ten-frame + hint
  stay visible).

Wired as skill `en-maketen` (band 2 math, c2-math-9, class 2), game
`game-maketen`, scene key `MakeTen`, bg "magic". i18n: 4 new mt* keys (EN + BN).
Bangla digits for the BN locale.
