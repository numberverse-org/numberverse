# #215 — Values: honesty — the truth game

**Status:** DONE · **PR:** #542 · **Branch:** feat/215-honesty

## Problem
A band-2 values game with gentle honesty scenarios (no shame). Requirement:
"8+ scenarios · Soft feedback · i18n clean."

## Fix
New `TruthScene` ("Truth star", skill `bgs-honesty`, c2-bgs-4, class 2):
- **12 everyday situations** (`hnSit1..12`) — broke a vase, ate the last
  chocolate, woke up late, found money on the floor, etc. Each shows an emoji +
  the situation (spoken en/bn) and two buttons: a **green truthful response**
  (`hnGoodN`) and a neutral untruthful one (`hnNotN`).
- **Celebrates honest choices**: truthful tap → `pop` + `win` + a ⭐/✨ star
  burst + a rotating praise (`hnPraise1..4`) floated and spoken aloud.
- **Soft feedback / no shame**: untruthful taps only get a gentle
  "Try telling the truth" (`hnTruth`) + a soft pulse on the truthful button —
  never a penalty, matching the Kind Heart philosophy.
- **Level ladder** [2,2,3,3,4,4] = scenarios per round; each round shuffles
  ALL 12 scenarios so every kid meets every situation.
