# #288 — Kid-friendly voice settings

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Kids have no way to make Nova's voice louder/softer themselves without going
through the parent settings. Acceptance: **2-3 options** · **easy reset** ·
**kid-safe UI**.

## Fix

A **🗣️ Nova's Voice** panel in the home "More ▾" menu (right beside the funny
voices): **Soft / Normal / Loud** + a one-tap **🔄 reset**. Sets a
device-local volume preference that applies to EVERY spoken line on BOTH
engines (Web Speech + the on-device neural Bangla voice).

- **Speech layer** (`game/speech.ts`) —
  - `getVoiceFunVolume()` / `setVoiceFunVolume(v)` / `resetVoiceFunVolume()`
    persist `nv_voice_fun_vol` in localStorage (Soft = 0.55, Normal = 0.9 the
    app default, Loud = 1.0).
  - `speak()` applies the preference to the neural path (was hardcoded 0.9)
    and `webSpeak` reads it too — a caller's explicit `opts.volume` (funny
    voices, whispers) still wins, so the shout/whisper play is untouched.
- **UI** (`App.tsx`) — a compact `.voice-fun` card with three pill buttons
  (active one highlighted) + reset. Tapping a level plays a quick "One two
  three!" so the kid HEARS the change instantly.
- **i18n** — 6 `Strings` entries EN + BN (`voiceFunTitle/Soft/Normal/Loud/
  Reset/Test`).
- **CSS** — `.voice-fun` + pill buttons (active glow) in styles.css.
- **Offline** — pure localStorage; no network.

## Files
