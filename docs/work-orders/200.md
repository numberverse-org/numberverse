# Work Order 200 — Math: elapsed time (how long until…)

**Issue:** #200
**Status:** DONE (PR #___)

## Problem
Band 3 kids read a clock but struggle with "how long until…?" — the minute
difference from now to a target time. They need the clock AND the digital target
together, with kid-friendly minute counts.

## Fix
New `ElapsedTimeScene` — compute minutes until a digital target:
- **Clock + digital:** an analog clock shows the START time; a gold chip shows the
  digital TARGET ("until 2:45"). "How many minutes until 2:45?" → tap the count.
- **Kid-friendly:** lvl 1–2 deltas 5/10/15/20/30 min on 5-min marks; lvl 3 up to
  45 min in 5s; lvl 4+ any 1–59 min. Targets stay within the next hour, the 12h
  clock wraps correctly (11:30 + 45 = 12:15).
- **Elapsed sweep:** on correct the hands tween forward from start to target — the
  arc the kid just counted IS the answer. "30 minutes" is spoken (etSpeak).
- Distractors are other deltas in the level pool; the correct count never
  repeats back-to-back.

Wired as skill `en-elapsed` (band 3 math, c3-math-12, class 3), game
`game-elapsed`, scene key `ElapsedTime`, bg "night". i18n: 7 new et* keys
(EN + BN). Bangla digits for the BN locale.
