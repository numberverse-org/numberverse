# Work Order — #167: Bangla matra matrix challenge (মাত্রা মিশ্রণ)

**Status:** ✅ Merged via PR #494

## Problem
Band 2 needs mixed-matra practice INSIDE real words (া ি ী ু ূ ে ো ৈ ৌ ৃ).
The existing band-4 BnMatrasScene isolates ক + া = কা combines; nothing puts a
matra in a word the kid already knows.

## Fix
New `MatraMatrixScene` (`apps/kid/src/game/MatraMatrixScene.ts`), band 2, scene
key `MatraMatrix`, skill `bn-matra-matrix` (c2-bangla-9), game `game-matramatrix`
(difficultyLevels `[3,3,3,4,4,4]` = matra tile count).

**Mechanic — word context, not isolated matras:**
- A picture clue (✂️) + the word with its matra slot empty (ক [◻] টা) are shown.
- The kid taps the matra that completes the word (া → কাটা).
- The matra tile snaps into the slot; the FULL word pops in; then the WORD and
  the MATRA NAME are both spoken (কাটা → আ-কার).
- Wrong matra: hintWrong retires the tile with a bilingual "doesn't make this
  word" nudge. EASY pool (levels 0-1) = া ি ু ে.

**Data:** 10 words, one per matra (≥ 8 required) — কাটা(া), মিল(ি), বীজ(ী),
ফুল(ু), দূরে(ূ), খেলা(ে), রোদ(ো), কৈ(ৈ), নৌকা(ৌ), কৃপণ(ৃ). Each satisfies
`word === head + matra + rest` (Bangla shaping renders the matra attached).
