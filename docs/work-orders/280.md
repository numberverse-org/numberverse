# #280 — Challenge Nova: beat-the-owl drill rounds

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

The owl is the kid's friend, but there's no optional head-to-head drill. Kids
who want a contest have nowhere to race Nova. Acceptance: **drill vs Nova** ·
**fair difficulty ramp** · **no ads**.

## Fix

A ⚔️ **Beat Nova** challenge card on home — an optional 5-round math duel vs
Nova the owl with a live scoreboard, gentle answer reveal, and a coin prize
inside the daily cap. Pure DOM overlay (like #292) — zero Phaser changes.

- **Fair difficulty ramp** — the starting level maps the kid's real average
  mastery (1–10); after each round the level goes **+1 on a hit** and **−1 on a
  miss**, so the questions track exactly where the kid is. 50k-question
  simulation confirms every level generates 4 unique, non-negative, correctly
  indexed choices.
- **Fair Nova** — the owl's hit-rate tracks the kid's own accuracy through the
  duel: a strong kid meets a strong owl, a struggling kid meets a gentler one,
  clamped to [0.35, 0.65] so it's always winnable but always a real contest.
- **Friendly scoring** — `You · Nova` scoreboard, correct-answer reveal teaches
  the right choice, win → 🏆 (3 coins), tie → 🤝 (2), close → 💪 (1); all paid
  by a new `novaChallengeReward` store action that still respects the daily
  anti-grind cap (`NOVA_DAILY_CAP`).
- **Locale-packed** (#131) — 22 new `Strings` EN + BN, Bangla digits via
  `bnNum`, universal math symbols.
- **No ads** — the economy stays 100% learning-only; the reward is coins that
  only decorate Nova, nothing paid.
- **Offline** — pure client state + localStorage.
