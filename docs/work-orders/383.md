# Work order #383 — Auth: parent gate signup/login is boring and confusing
> milestone:  · branch: `feat/issue-383`

## Goal
Redesign the parent gate: one clear path, show/hide password, friendly hints, less form friction.

## Done when
- [x] Single clear action per mode
- [x] Show/hide password
- [x] Friendlier copy + hints EN+BN

## What shipped
- **One clear action per mode** (`apps/kid/src/App.tsx`): the redundant
  mode-switch link under the submit button is gone — the Sign in / Create
  account tabs are the single switch, and the submit button is the single
  action. Button labels dropped the "…& show the syllabus" tail: now just
  "🔓 Sign in" / "✨ Create account" (short enough to read at a glance).
- **Show/hide password**: an eye toggle (👁️/🙈) sits inside the password
  field (`pass-wrap`), with `gateShowPass` state and an `aria-label` +
  `aria-pressed` for accessibility. No more squinting to check a typo.
- **Live password hint**: in Create-account mode a one-line hint shows under
  the field ("Use at least 6 characters…") and flips green ("Great — that's
  long enough!") the moment it's valid — the parent always knows what's left.
- **Friendlier copy**: `gateSub` shortened to the essential promise ("Sign in
  to keep your child's learning safe and see their progress." / BN), in both
  languages. Removed the now-unused `gateToggleUp`/`gateToggleIn` strings and
  `.gate-toggle` CSS.
- **Unused strings + CSS removed**: `gateToggleUp`/`gateToggleIn` from the
  `Strings` interface and EN+BN maps; `.gate-toggle` rule deleted.
