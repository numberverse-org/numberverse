# Work Order 194 — Math: multiplication arrays (visual times tables)

**Issue:** #194
**Status:** DONE (PR #521)

## Problem
Band 2/3 kids need times tables taught with countable arrays BEFORE abstract
numbers — see the dots, count rows × columns, match the equation.

## Fix
New `ArrayMultScene` — dot-array matching game:
- **Array → equation:** each question draws an a×b dot array (green first
  row/column highlights) with row badges 1..a on the left and column badges
  1..b on top. The kid taps the full equation card that matches — "3 × 4 = 12".
- **Facts 2–5:** factors 2–3 (lvl 1–2), 2–4 (lvl 3), 2–5 (lvl 4+). Products up
  to 25. Correct tap speaks "3 times 4 is 12!".
- **Distractors:** 3 other valid arrays (different factors and products) picked
  from all 2..5×2..5 pairs, excluding the answer, its commutative twin (b×a),
  and any equal-product pair (no ambiguity). Min 14 candidate pairs available.
- Wrong tap → shake + dim + green reveal of "3 × 4 = 12".

Wired as skill `en-array-mult` (band 2 math, c2-math-12, class 2), game
`game-array-mult`, scene key `ArrayMult`, bg "desert". i18n: 5 new am* keys
(EN + BN). Bangla digits for the BN locale.
