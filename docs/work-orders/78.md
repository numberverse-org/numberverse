# #78 — Parent panel: per-day wrong-answer history per kid

**Status:** 🚧 in progress (feature branch `feat/issue-78`)

## Problem

The parent panel showed *which* skills a kid was stuck on ("Needs a little
help") but not *when* — a parent couldn't see that Tuesday was full of
regrouping mistakes, or whether a tricky skill improved across the week.

## Done-when (from the issue)

- [x] **Calendar heatmap of wrongs per day** — a 28-day grid (7×4, oldest →
      newest) under "❌ Wrong answers" in the panel, each day colored by wrong
      intensity (1 / 2–3 / 4+).
- [x] **Drill-down to skill + wrong count** — tap a day → the exact skills and
      wrong counts for that day (skill title EN + BN).
- [x] **Uses the existing mistakes ledger** — the `mistakes` map (kid+skill
      key) is extended with a `byDay` bucket; the heatmap is derived entirely
      from it.
- [x] **Works offline, no analytics** — all local, reactive to the store, zero
      network calls.

## Design

- `MistakeState` gains `byDay: Record<string, number>` (ISO `'YYYY-MM-DD'` →
  wrong taps). `recordWrong()` bumps the bucket for today; every path through
  the ledger is normalized so pre-#78 persisted entries (no `byDay`) still read
  as `{}` — no data migration needed, old saves survive.
- The panel's "❌ Wrong answers" `<details>` card builds a per-kid, per-day,
  per-skill map from the store's reactive `mistakes`, renders the heatmap, and
  drill-down lists skills (filtered to the selected kid; the parent kid-picker
  still drives which kid).
- Selected day falls back to the most recent day with wrongs — the card never
  invents an empty day. Live-updates as the kid plays (reactive selector).
- Full EN/BN parity; weekday header is language-neutral letters.
