# #79 — Parent: mastery timeline

## What
New 🏆 **Mastery timeline** card in the parent dashboard — every skill the kid
has mastered, newest first, with the date it was first won (EN + BN titles).

## Backend
- `SkillMastery.mastered_at` — set ONCE the moment mastery first crosses ≥80%
  (never overwritten, even if mastery later decays below 80%).
- `MasteryOut.mastered_at` exposed on both `GET /kids/{id}/mastery` and the
  snapshot endpoint.
- One-time idempotent backfill in `migrations.py` at boot: rows already ≥80%
  before this column existed get their `last_practice` as the proxy date.

## Portal
- `TIMELINE_LANGS` EN + BN (same country-pack seam).
- `masteryTimeline` derived from already-loaded mastery rows → offline after load.
- `shortDate()` renders "12 Aug" / "১২ আগস্ট".

## Files
- `apps/api/app/models.py` — `mastered_at` column
- `apps/api/app/routers/progress.py` — stamp on first ≥80% + expose in both endpoints
- `apps/api/app/schemas.py` — `MasteryOut.mastered_at`
- `apps/api/app/migrations.py` — idempotent backfill
- `apps/parent/lib/api.ts` — `MasteryRow.mastered_at?`
- `apps/parent/app/page.tsx` — `TIMELINE_LANGS`, derived timeline, card, `shortDate`
- `apps/parent/app/globals.css` — `.timeline-*`
