# Work Order 211 — ICT: device manners — on/off & wait

**Issue:** #211
**Status:** DONE (PR #538)

## Problem
A band-1 digital-citizenship game teaching safe offline device habits. Kids
need to learn the right way to turn a device on and off — press power, WAIT
for it to boot (no button-mashing), and confirm before sleeping it.

## Fix
New `DeviceMannersScene` — a friendly cartoon tablet with a real power button:
- **Turn-on sequence:** the tablet starts dark; the kid taps the green power
  button once → a boot progress bar fills over a few seconds (longer each
  level) → the screen lights up with app dots + 😊 and speaks "The device is
  on!"
- **Patience scenarios:** from lvl 2 a tempting green "👆" bubble bounces
  during boot. Tapping it is never punished — just a gentle "Not yet — wait a
  little!" (spoken + floated) and the boot continues.
- **Turn-off sequence:** the lit tablet shows a red power button → tap it →
  "Turn off" / "Cancel" buttons appear → tapping Turn off dims the screen to
  😴 and speaks "The device is off!"; tapping Cancel gently returns to "on"
  and re-asks.
- **No network features:** 100% offline — nothing fetches, phones home, or
  needs connectivity.
- **Speaks every step** in EN or BN.

Lvl 1–2 boot (turn on), lvl 3–4 power off, lvl 5–6 random. Wired as skill
`ict-device-manners` (band 1 ICT, c1-ict-3, class 1), game `game-device`,
scene key `DeviceManners`, bg "magic". i18n: 14 new dm* keys (EN + BN).
