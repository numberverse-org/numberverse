# Work Order #222 — English: irregular plurals

**Status:** DONE · **PR:** #549 · **Branch:** feat/222-irregular-plurals · **Merge:** main

## Problem
Band-3 grammar gap: kids only meet regular -s/-es plurals. Issue asks for 12+
nouns practicing irregular plural forms, fun visual pairs, i18n clean.

## Fix
New `IrregularPluralsScene` — "Make it plural!": one noun + emoji shows
("one foot 🦶") and the kid picks the plural for "two ___?" from 3 options.

- **14 irregular pairs** — internal vowel change (foot→feet, tooth→teeth,
  mouse→mice, man→men, woman→women, goose→geese), -en (child→children,
  ox→oxen), and no-change (sheep→sheep, fish→fish, deer→deer), plus f→v
  (leaf→leaves, knife→knives). Every pair has an emoji picture hint.
- **Shuffle-bag + round-level dedupe** — bag-refill boundary never repeats an
  id already shown in the round (300k-round sim: 0 dups).
- **3 string-distinct options** — correct appears exactly once, all real
  plural words as distractors.
- Correct tap → "Perfect! foot → feet" float + audio + full "one foot, two
  feet!" spoken; wrong tap → gentle "Not quite" nudge.
- Ladder `[4,4,6,6,8,8]`, `ROUNDS_TO_FINISH = 3`, bg "magic".
