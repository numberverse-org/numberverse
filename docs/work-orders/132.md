# #132 — Printable worksheet generator (offline PDF)

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Parents asked for something printable — "what should my kid practice this
week?" with actual problems, offline-friendly.

## Fix

**New API** `GET /api/v1/kids/{kid_id}/weak-skills` — skills below mastery
(`< 0.7`, weakest first) joined with catalog titles/subject/band.

**Parent portal** — a "📄 Printable worksheet" card per kid. Clicking it:
1. fetches weak skills,
2. `apps/parent/lib/worksheet.ts` generates practice problems (deterministic
   seeded LCG):
   - arithmetic skills → real `a + b`, `a − b`, `a × b`, `a ÷ b`, number
     bonds, fractions, time, money (৳), place value, decimals/percent, area,
   - counting/letters/science/values → an at-home activity line ("Play X in
     the app — you've tried N times, got M right"), since a worksheet can't
     fake a pre-reader decode,
3. renders a print-only sheet; `window.print()` → clean A4 (CSS
   `@media print` hides everything but the sheet).
