# #22 — Sibling co-op on one device

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Two kids, one tablet — the sibling sits and watches instead of playing. The
issue's acceptance: **profile toggle mid-session; per-kid progress stays
separate.**

## Fix

A "pass the device" affordance that hands a live session to a sibling:

- **HUD co-op button** — during a game, when ≥2 profiles exist on the device,
  a `👥` button sits beside the music toggle. One tap opens a "Pass the
  device" sheet listing every profile with its avatar, the current player
  marked **You**; tapping a sibling hands the device to them.
- **Mid-session toggle** — switching kids re-runs the playing effect (`kid`
  is a dependency), which restarts the CURRENT step scene for the new kid
  with their own name, per-kid level ladder (`adaptiveLevelIndex`), and
  wrong-ledger context. The session position and step sequence are preserved,
  so both kids co-play the same session — alternating turns, exactly the
  issue's ask.
- **Per-kid progress stays separate** — no new storage needed: every
  progress write is already keyed `${kidId}:${skillId}` (skills/moni/stats/
  pet/coins), so a round played under a sibling records to THAT sibling.
  Wrongs, mastery, Moni plans, stars and coins never bleed across kids.
- **Feedback** — a short "X is playing now" toast (`nowPlaying`) confirms the
  hand-off; the remembered active kid (`nv_kid_id`) updates so the app reopens
  on the last player.
- **Locale-pack clean** — all new copy lives in the EN/BN string tables
  (`siblingCoop/passDevice/passTo/nowPlaying/youBadge/coopHint`), so a new
  language is a config addition (#131).
