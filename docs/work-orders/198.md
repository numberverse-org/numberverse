# Work Order 198 — Math: decimals — tenths place value

**Issue:** #198
**Status:** DONE (PR #___)

## Problem
Band 3 kids need decimals to tenths read and built in 0.1 steps — seeing a
10-cell strip where every cell is 0.1 makes 0.3 = 3/10 concrete, and the
place-value naming ("three tenths") ties the digit to the position.

## Fix
New `DecTenthsScene` — read & build on a 10-cell strip:
- **Grid shading:** a row of 10 large cells (each = 0.1). READ shows k green
  cells; BUILD starts empty and the kid taps cells to shade them (toggle, green).
- **Read the decimal:** "What decimal is shaded?" → tap the matching 0.3 from
  4 option cards (0.0–1.0 in 0.1 steps). Correct floats "3/10 = 0.3".
- **Build the decimal:** "Shade 3 tenths" → tap cells (live 0.0…1.0 counter
  above the strip), ✅ checks the count. Wrong → "Shade 3 cells" hint.
- **Place-value speech:** every correct answer speaks "3 tenths" (deSpeak) in
  the active locale.

Tenths: 1–5 (lvl 1–2), 1–9 (lvl 3), 0–10 (lvl 4+, includes 0.0 and 1.0). READ
and BUILD alternate every question. Distractors are other tenths in range — no
repeats of the target value.

Wired as skill `en-dectenths` (band 3 math, c3-math-10, class 3), game
`game-dectenths`, scene key `DecTenths`, bg "space". i18n: 7 new de* keys
(EN + BN). Bangla digits for the BN locale.
