# Work order #326 — Moni: weekly insight card for parents
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-326`

## Goal
A parent card summarizing Moni's per-kid reads: learning style, pace, best game, next move.

## Done when
- [x] Derived from profile
- [x] Bangla+EN
- [x] Uses local data

## What shipped
- **Weekly insight strip** (`📅 This week`) inside the parent Moni card
  (`apps/kid/src/App.tsx`): a collapsible block that reads the last 7 days
  straight from Moni's LOCAL profile.
  - **Rounds** + **accuracy** this week, computed from `profile.recent[]`
    timestamps (newest-first, capped at 20 — enough signal for a week).
  - **Pace vs the child's own lifetime accuracy**: "Stronger than usual 💪",
    "A bit softer this week 🐢", or "Steady as always ⚖️" (within ±5%).
  - **Learning style badge** via `deriveLearningStyle(profile.style)` →
    "⚡ Speed Sprinter / 🐢 Steady Pal / 🦉 Friend of All" — same classifier
    Nova already wears, now parent-facing.
  - **Best game** this week from `style.gameAffinity` (highest engagement),
    prettified id → "Count Pop", "Balloon Pop", etc.
  - **Next move**: the card's existing "next move" line (plan focus) stays as
    the call-to-action under the weekly reads.
- **Derived from profile**: every value is computed from the existing
  `MoniProfile` — no new state, no new storage.
- **Bangla+EN**: all labels + pace/style phrases localized (`moniWeek*`,
  `moniStyle*`).
- **Uses local data**: purely the Zustand store; zero network. Hidden when
  there's no play in the last 7 days — the card never invents a week.
