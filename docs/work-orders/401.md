# Work order #401 — /parent redirect must preserve https
> milestone: bangla-ux-wave · branch: `feat/issue-401`

## Acceptance criteria (from the issue)
- [x] curl -I https://kids.munna-khan.xyz/parent → 302 Location https://…/parent/
- [x] /admin same

## Goal
The `/parent` → `/parent/` 302 from origin nginx used `$scheme` = http (Cloudflare
terminates TLS and talks to the origin over plain http), so browsers were handed
a `http://` Location on an auth-bearing portal. Wrong.

## What shipped
- `infra/deploy/nginx.conf`: `location = /parent` and `location = /admin` now
  emit `https://$host/…/` when `$http_x_forwarded_proto = "https"`, else the
  plain `return 302 /…/` (LAN / local http fallback).
- `if` + `return` is the one safe use of `if` in nginx.

## Notes
- Config is baked into the web image via `COPY infra/deploy/nginx.conf
  /etc/nginx/conf.d/default.conf` → needs the release pipeline to take effect.
- Verify after release: `curl -s -D - -o /dev/null
  https://kids.munna-khan.xyz/parent | grep -i '^location'` → https URL.
