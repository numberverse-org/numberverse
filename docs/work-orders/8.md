# #8 — Weekly share card: coins + minutes breakdown

## What
- **Share card page** (`/share/?t=…`) now shows a 🪙 wallet tile (when non-zero)
  and a 7-day **minute curve** (zero-identity floats, no dates).
- **WhatsApp caption** (`weeklyShareText`) gains an honest coins line — the
  current wallet balance, never a made-up "earned this week" (there is no
  per-week coin ledger; the caption stays truthful).

## Backend
- `ShareSnapshotOut` + `weekly` now carry `coins` (current wallet) and the
  snapshot carries `minutes_by_day` (7 floats, oldest→newest, zero-filled).

## Files
- `apps/api/app/routers/shares.py` — snapshot coins + minute curve
- `apps/api/app/routers/kids.py`, `apps/api/app/schemas.py` — `WeeklyOut.coins`
- `apps/parent/lib/api.ts` — `ShareSnapshot.coins/minutes_by_day`, `WeeklyReport.coins`
- `apps/parent/app/page.tsx` — honest coins line in `weeklyShareText`
- `apps/parent/app/share/page.tsx` — wallet tile + minute bars
- `apps/parent/app/globals.css` — `.share-minbars` etc.
