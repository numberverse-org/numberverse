# Work Order 208 — Science: magnets — attract/repel (predict, then try it)

**Issue:** #208
**Status:** DONE (PR #535)

## Problem
"Opposite poles attract, same poles repel" is a sentence until you SEE it. The
first thing a child does with a magnet is try it — so the game predicts first,
then literally performs the trial.

## Fix
New `MagnetPolesScene` — predict attract/repel, then try it:
- **Pole visuals:** two magnets face each other with their pole caps colored
  and lettered — red **N** (0xef4444) and blue **S** (0x3b82f6). The fixed
  magnet's RIGHT end faces the movable magnet's LEFT end, so the facing poles
  are obvious at a glance.
- **Predict-then-try:** the kid taps **Attract** or **Repel**. Then the movable
  magnet DOES it: attract → snaps onto the fixed magnet with a ✨ spark and a
  magnet-pop; repel → stops short and bounces back to its perch. Wrong
  predictions still play the TRUE animation so the rule is always demonstrated.
- **Try-both-ways:** every round re-randomizes the facing poles — sometimes the
  kid sees the same pair from the other side on the next round, reinforcing
  that N↔S attracts and N↔N / S↔S repels regardless of left/right.
- **Speaks** the rule: "Opposite poles attract" / "Same poles repel".
- **Lvl 1–2** always face mixed poles (always attract), lvl 3+ all 4 pairings.

Wired as skill `en-magnets` (band 2 science, c2-science-9, class 2), game
`game-magnets`, scene key `MagnetPoles`, bg "magic". i18n: 9 new mg* keys
(EN + BN).
