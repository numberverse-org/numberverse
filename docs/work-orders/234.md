# #234 — ICT: tap/drag accuracy trainer

**Status:** ✅ done

## Problem
Band-1 (ages 3–5, ICT) needed a fine tap/drag motor-skills game with friendly
targets: 3 difficulty tiers, gentle scoring, i18n clean.

## Fix
New Phaser scene `CatchBugScene` (`apps/kid/src/game/CatchBugScene.ts`) —
"**Catch the Bugs**". A bug bobs at a random spot; TAP it. From tier 2 on a
butterfly must be DRAGGED into the net.

- **3 difficulty tiers** (big → small targets, tap-only → +1 drag → +2 drags):
  - tier 0 (levels 0-1): tap-only, 54px bugs, generous 40px hit.
  - tier 1 (levels 2-3): tap 44px bugs + DRAG one 🦋 into the net.
  - tier 2 (levels 4-5): tap 36px bugs + drag TWO butterflies.
- **Gentle scoring** — no timer, no penalty: every catch pops a sparkle +
  "Great!"/সাবাশ!; a missed drop just floats "Try again!" and the butterfly
  glides back. Round-end "Woo-hoo!"/চমৎকার!.
- **Difficulty ladder** — `game-tapdrag` `[4,4,5,5,6,6]` = critters per round.
- **New subject** — `ict` added to the catalog (`SUBJECTS_SEED`), so the skill
  has a real subject row (FK-clean).
- **i18n clean** — EN + BN for every instruction, counter, and cheer.
