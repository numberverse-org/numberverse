# #92 — No-ads: CI scan that no ad/tracker SDK ever lands

**Status:** 🔜 in progress (PR open)

## Problem

Numberverse is 100% ad-free, but nothing *enforced* it — a contributor could
`pnpm add mixpanel-browser` or paste a doubleclick.net call and it would ship
silently.

## Fix

New `scripts/tracker-scan.mjs` + `tracker-scan` CI job:

- **Dependency scan** — every workspace `package.json` against a blocklist of
  ad/analytics/tracker SDK names (`adsbygoogle`, `google-analytics`, `ga-4`,
  `mixpanel`, `segment`, `amplitude`, `posthog`, `fullstory`, `hotjar`,
  `fathom`, `plausible`, `facebook-pixel`, …). Exact match — `react-admin`
  can never trip `admin`.
- **Endpoint scan** — shipped source (`apps/kid/src`, `apps/parent/app`,
  `apps/admin/src`, `packages/core/src`) against SDK call shapes + domains
  (`adsbygoogle`, `doubleclick.net`, `googletagmanager.com`, `mixpanel.com`,
  `fbq(`, `analytics.google`, `branch.io`, …). Mirrors the Oracle's `AD_SDKS`.
- Fail-closed, **clear error** names the package/file + fingerprint.

## Files
