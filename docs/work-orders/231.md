# #231 — Sink or float predict

**Status:** ✅ done

## Problem
Band-2 (ages 4–6, science) needed a game predicting whether objects sink or
float, with predict-then-check feedback, i18n clean.

## Fix
New Phaser scene `SinkFloatScene` (`apps/kid/src/game/SinkFloatScene.ts`):

- **15+ objects** — 16 real-world objects (🦆🍃🪨🔑⛵🧱🎈🪙🪶🧊🍎🥄🛶🚗🪵📱),
  ordered obvious → tricky. Emoji labels are language-neutral; the word in the
  question/speech localizes EN/BN.
- **Predict-then-check** — the kid predicts Sink vs Float on a water tank; ANY
  tap reveals the object's TRUE behavior (drops to the bottom or bobs at the
  surface). A wrong guess still teaches: gentle "Oops — it sank!" + the reveal.
  Correct → pop/win/sparkle, wrong → soft nudge.
- **Difficulty ramp** — the object pool grows with level (8 → 12 → 16).
- **i18n clean** — localized header, question, reveal feedback (correct +
  wrong variants) and speech lines all EN + BN.
