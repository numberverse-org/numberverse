# #136 — Big-screen / classroom projector mode

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Teachers want a focused classroom display: large type, high contrast, no
parent UI, keyboard play.

## Fix

- **`📽️ Classroom projector` toggle** in Settings → Screen (localStorage
  `nv_projector`, `role="switch"` + announce for screen readers).
- When on, the home screen gets `.projector-mode`: ~118% base font, huge
  play button, bigger journey/rank/season/festival text, thicker path border,
  high-contrast. Auto-fullscreen on enable; Esc exits.
- **No parent UI**: the settings gear + voice chips are hidden while
  projector is on (only the play path + journey remain).
- **Keyboard nav**: Enter on home plays the next lesson (`playRef` +
  `onKeyDown`); hint line "Press Enter to play · Esc to exit fullscreen".
- i18n: `projector*` STR keys (EN + BN).
