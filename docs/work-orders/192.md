# Work Order 192 — Math: 2-digit addition with regrouping (visual)

**Issue:** #192
**Status:** DONE (PR #___)

## Problem
Band 2 kids need the written method for carrying taught visually, not as an
abstract rule — with base-10 blocks and a step-by-step scaffold.

## Fix
New `AddRegroupScene` — a written-method box (tens/ones columns, addend rows,
answer row) plus base-10 blocks:
- **Step-by-step scaffolding:** Step 1 "Add the ones" (active column
  highlighted white) — kid picks the ones digit from 4 options; ones cubes are
  drawn for both addends. Step 2 "Add the tens + carry" — kid picks the tens
  digit; tens bars + a green carry bar are drawn. The full sum is spoken and the
  tens strategy "3 + 2 + 1 = 6" floats up.
- **Regroup animation:** every question forces a carry (ones sum ≥ 10). On the
  correct ones digit, 10 mini-cubes lift out of the ones column and shrink into
  a green "Carry 1!" chip above the tens column, with a pop + spoken "Carry 1!".
- **Generation:** tensMax 3/5/7 by level so tens digit stays ≤ 9 (2-digit
  results only); ones digits always sum to 10–18.
- Wrong answer → shake + dim + green reveal + hint ("7 + 5 = 12 → ones digit 2").

Wired as skill `en-addregroup` (band 2 math, c2-math-10, class 2), game
`game-addregroup`, scene key `AddRegroup`, bg "kitchen". i18n: 8 new ar* keys
(EN + BN). Bangla digits for the BN locale.
