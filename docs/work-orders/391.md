# Work order #391 — Auth: Google button shows a surprise language ("Weiter mit Google")
> milestone:  · branch: `feat/issue-391`

## Goal
The GIS "Continue with Google" button auto-localizes from the browser /
Google-account locale, so a parent saw **"Weiter mit Google"** (German). Pin it
to the app language.

## Done when
- [x] Google button always matches app UI language (bn → বাংলা, en → English)
- [x] Re-renders when the parent switches language
- [x] Never auto-localizes to a surprise language again

## What shipped
- **`GoogleSignIn.tsx`**: new `lang` prop → `gid.renderButton({ …, locale })` is
  now `"bn"` for a Bangla app and `"en"` for an English app — Google is no
  longer allowed to pick the button language from the browser/account.
  - `container.innerHTML = ""` before re-render (GIS throws on a container
    that already holds a button), and the effect now depends on `[lang]` so a
    language switch actually re-renders the button.
  - `setFailed(null)` on re-run so a stale fallback note never lingers across
    a language switch.
- **`App.tsx`**: passes `lang={lang}` at the parent gate.
