# #287 + #293 — Quest mission variety

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

The Daily Quest is always the same goal ("play 3 rounds"). Acceptance (both
#287 and #293): **4+ quest types** · **reward parity** · **i18n clean**.

## Fix

The daily mission TYPE now **rotates per kid per day** — a deterministic hash
of `kidId:date` picks it, so it's stable across reloads and fully offline.

- **4 quest types** (`store.ts`):
  - `rounds` — play 3 rounds (existing behavior preserved).
  - `stars` — earn 8 stars (correct answers).
  - `master` — master one skill (a round that crosses the mastery bar).
  - `newgame` — try a brand-new game (a skill never attempted before).
- **Reward parity** — every type pays the same `NOVA_QUEST_REWARD` (5 🪙),
  inside the same daily anti-grind cap.
- **Progress is type-aware** — a round only counts when it matches today's
  type: correct answers feed `stars`, mastery-crossings feed `master`, first-
  ever attempts feed `newgame`, every round feeds `rounds`.
- **Migration courtesy** — older saves with `questRounds` but no
  `questProgress` still count rounds-type progress for the day.
- **UI** (`App.tsx`) — the home quest chip shows the day's goal name (e.g.
  "Earn 8 stars · 4/8" with the progress bar) in the app's language. The
  completion cheer is unchanged (same bonus, same tada + speak).
- **i18n** — 4 new `Strings` entries EN + BN (`questTypeRounds/Stars/Master/
  Newgame`), `questProgress` is now a pure `${n}/${target}` counter (Bangla
  digits via `bnNum`). Locale-extensible (#131).
