# #219 — Bangla: classifiers & postpositions (গুলো/টাকে)

**Status:** DONE · **PR:** #546 · **Branch:** feat/219-classifiers

## Problem
A band-3 grammar game placing the right classifier/postposition in a sentence.
Requirement: "15+ sentences · Tap-to-insert · i18n clean."

## Fix
New `ClassifiersScene` ("Word fit", skill `bn-classifiers`, c3-bangla-9,
class 3):
- **16 sentences** with a blank for a classifier (টি/টা/গুলো/খানা) or
  postposition (থেকে, পাশে, ভিতরে, সঙ্গে, জন্য, সামনে, উপরে, নিচে…):
  "আমার বই ___ পড়ে আছে।", "বিড়াল ___ টেবিলে উঠেছে।", "মেয়েটি স্কুল ___ আসছে।",
  "এই কেকটি মায়ের ___।" etc. — each with an emoji picture context.
- **Tap-to-insert**: the sentence shows with a "______" blank; the kid taps
  one of three word buttons to INSERT it. Correct → the word fills the blank,
  the full sentence is spoken aloud, pop + win; wrong → gentle shake + "try
  again" (no penalty).
- **Options are 3 distinct strings** — some classifiers/postpositions repeat
  across sentences (পাশে, টা, উপরে), so distractors that would duplicate the
  correct word (or each other) are filtered out.
- **Shuffle-bag** over all 16 + round dedupe guarantee every sentence is met,
  never twice in one round.
- **Level ladder** [4,4,6,6,8,8] = sentences per round. EN locale mirrors the
  exercise with the parallel English word (article/preposition).
