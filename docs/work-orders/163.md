# Work Order #163 — Bangla: antonyms & synonyms pairs (বিপরীত / সমার্থক)

**Status:** ✅ Merged via PR #490

## Problem
Band-2/3 vocabulary needs more than single words — kids must see how words
relate (opposites, same meaning). There was no Bangla word-relationship game.

## Fix
New `WordPairsScene` (key `WordPairs`, skill `bn-word-pairs`,
game `game-wordpairs`, band 2):

- **22 antonym pairs + 22 synonym pairs** (done-when: 20+ each): everyday words
  (বড়/ছোট, গরম/ঠান্ডা, দ্রুত/ধীর, দিন/রাত … সুন্দর/চমৎকার, জল/পানি, খুশি/আনন্দ …).
- **Picture-backed:** every word carries an emoji; the target shows emoji + word
  big, and every option card is `emoji + word` — the skill is meaning, not
  decoding.
- **Antonym ↔ synonym alternate** question by question (`wpAntonym` /
  `wpSynonym` prompt), each read aloud in warm Bangla; the correct pair is
  spoken together as a reward.
- **Difficulty ladder** `[3,3,4,4,4,4]` = option count (3 → 4).
- Wrong options retired gently via `hintWrong`; correct taps fire combo
  fireworks. 5 questions per round, 3 rounds per level.
