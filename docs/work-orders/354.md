# #354 — Sound-mixing balance

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Volumes were correct-ish but scattered as magic numbers across `audio.ts`, so
"the mix" wasn't a thing anyone could tune or audit. Acceptance: **levels
defined** · **mute respected**.

## Fix

A single **MIX** table in `game/audio.ts` — one knob per layer, and a
documented hierarchy:

```
music  ≈ 0.04–0.06   the lowest bed — ducks under everything
sfx    ≈ 0.05–0.16   the feedback layer — above music, below voice
voice  ≈ 0.9–1.0     the star (neural 0.9 default; WebSpeech = system vol)
```

- Every SFX now reads `MIX.*` (`sfxPop` 0.15, `sfxBad`/`sfxBadSecond`
  0.13/0.1, `sfxWin` 0.16 + sparkle 0.08, `sfxClick` 0.08 + second 0.06,
  `sfxTada` 0.1 + sparkle 0.12, `sfxStarPop` 0.05, `sfxCombo` 0.11,
  `sfxNote` 0.15). Same mix as before — the pass **defines** the levels, it
  doesn't drift them.
- Per-land music themes keep their flavour volumes (0.04–0.055 melody /
  0.045–0.06 bass) and are documented as the themed override of the MIX base.
- **Mute respected** — unchanged and verified: music mute (`musicMuted` in the
  scheduler) silences every theme; speech mute (`setSpeechEnabled`) silences
  both engines; haptics have their own switch (#355). The MIX table is
  independent of both, so toggling mute never resets levels.
