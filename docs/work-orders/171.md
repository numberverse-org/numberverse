# Work Order — #171: Bangla time words ordering (কাল-আজ-আগামীকাল)

**Status:** ✅ Merged via PR #498

## Problem
Band 1 had no temporal-sequencing skill. Kids know yesterday/today/tomorrow
intuitively but need to read and ORDER the Bangla words (গতকাল → আজ →
আগামীকাল) on a calendar.

## Fix
New `TimeWordsScene` (`apps/kid/src/game/TimeWordsScene.ts`), band 1, scene key
`TimeWords`, skill `bn-time-words` (c1-bangla-6), game `game-timewords`
(difficultyLevels `[0,0,1,1,2,2]` = off-timeline distractor count).

**Mechanic — temporal ordering with calendar visuals:**
- Three calendar boxes on a timeline (white card + gold binding bar) at
  past → now → future positions.
- Three event cards, each stamped with a time word (🎂 গতকাল, 📚 আজ, 🏖️
  আগামীকাল), are shuffled. The kid taps them in temporal order; each flies
  into its calendar slot and the time word is SPOKEN.
- Out-of-order target taps are coached (keepOnWrong — "which came first?");
  higher levels add DISTRACTOR words (গত সপ্তাহ, আগামী মাস…) that never belong
  on today's timeline and get retired when tapped.

**Data:** 6 event sets (each exactly one yesterday/today/tomorrow, unique
emojis within a set) + 4 distractor time words.
