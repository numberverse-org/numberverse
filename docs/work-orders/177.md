# Work Order — #177: English sight words level 3 (3rd 100)

**Status:** ✅ Merged via PR #504

## Problem
The sight-words skill only covered ~24 words. Reading fluency needs the full
high-frequency ladder — level 3 means the Fry 3rd-100 list — so the same game
had to grow from 24 to a complete 124-word pool (24 base + 100 level-3).

## Fix
Extended the existing `SightWordsScene` (scene key `SightWords`, skill
`en-sightwords`, game `game-sightwords`) — same game, bigger pool, richer modes.

- **All 100 words (done-when):** added the complete Fry 3rd-100 list
  (`WORDS_L3` — high, every, near, add, food, between, own, below, country,
  plant … family, it's) alongside the original 24-word base set → 124-word pool
  with zero duplicates.
- **Tap-the-word + read modes (done-when):** rounds alternate ~50/50:
  - **HEAR mode** — the spelling is hidden (🔊 shown), the word is spoken, the
    kid taps the word they hear; a 🔊 replay button re-speaks it. On solve the
    spelling is revealed and said aloud.
  - **READ mode** — the spelling is shown, the kid reads it and taps the
    matching card; the word is spoken on solve.
- Existing mechanic unchanged: word shown/spoken → tap the matching card among
  3-10 options; wrong taps retire that card via the hint system.
