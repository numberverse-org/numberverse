# #282 — Same-device sibling leaderboard

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Siblings on one device can't see how they're doing against each other.
Acceptance: **per-kid totals** · **no cloud** · **privacy-safe**.

## Fix

A **🥇 Sibling Leaderboard** screen that compares ONLY the kids on this device
— nothing leaves the phone (privacy-safe by construction, and it reuses the
#22 co-op spirit: two kids, one device).

- **Ranking** — device kids sorted by **skills mastered**, tie-broken by
  stars. Every row still shows the full per-kid totals (🏅 mastered · 🎮
  rounds · ⭐ stars), so a younger sibling's smaller mastery count never hides
  their play effort.
- **Medals** — 🥇🥈🥉 for the top 3, `#N` beyond; the active kid's row is
  highlighted with a "You"/"তুমি" pill.
- **Empty state** — with fewer than 2 kids, a warm message + "Add sibling"
  button (→ the add-kid flow) instead of an empty list.
- **Entry points** — a 🥇 quick-icon on the home screen AND a 🥇 button in
  the kid-picker header (so siblings can compare before anyone logs in).
- **i18n** — 10 `Strings` entries EN + BN (`lbTile/Title/Sub/Stat*/You/Empty/
  AddSibling/Speak`), Bangla digits via `bnNum`. Tapping a row speaks the
  kid's rank.
- **Offline** — reads `kids` (local React state) + `stats` + mastery from the
  local store only.

## Files
- `apps/kid/src/App.tsx` — `leaderboard` screen + entry points, Strings EN+BN
