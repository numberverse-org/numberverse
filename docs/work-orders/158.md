# #158 — Bangla: consonant conjunct speed drill

**Status:** ✅ done

## Problem
Band-3 Bangla reading drill for the most common conjunct letters in real words,
with a timer-based streak.

## Fix
New Phaser scene `ConjunctFindScene` (`apps/kid/src/game/ConjunctFindScene.ts`):

- **25 conjuncts in word context** (20+ required) — ক্ষ পক্ষ, ঞ্জ অঞ্জলি, ঙ্ক
  অঙ্ক, ণ্ড মণ্ডল, ঙ্খ শঙ্খ, ক্ত মুক্ত, ষ্ট মিষ্টি, ন্ত শান্ত, স্প স্পষ্ট, ল্ল
  বিল্লি, ত্ত সত্তর, ত্ম আত্মা, প্প টিপ্পনী, ম্ম সম্মান, ন্ন অন্ন, ড্ড হাড্ডি,
  জ্জ উজ্জ্বল, ঙ্গ সঙ্গ, ঞ্চ পঞ্চ, ষ্ণ তৃষ্ণা, ত্থ উত্থান, শ্ন প্রশ্ন, ল্প গল্প,
  র্য সূর্য, ন্দ বিন্দু. The 12 most common form the easy pool for levels 0-1.
- **Tap the conjunct shown** — a conjunct (ক্ষ) is shown big; three word cards
  appear; tap the word that CONTAINS it. Distractor words never contain the
  target (validated — every deal has exactly one correct card).
- **Timer-based streak** — a countdown bar (12s → 7s by level). Answer in time →
  streak 🔥 grows; a miss or timeout resets it gently, no harsh fail.
- **Escalating hints** — hintWrong's ladder: nudge → coaching → reveal the
  correct card on repeated misses.
- **i18n clean** — EN + BN for every prompt, streak, timeout, and cheer.
- Fixed a real Unicode data bug the 200k sim caught: "বাংলা" is spelled with
  anusvara ং (বাংলা), NOT the ঙ্+গ conjunct — the ঙ্গ example is now "সঙ্গ".
