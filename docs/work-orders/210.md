# Work Order 210 — ICT: keyboard explorer (letters & numbers)

**Issue:** #210
**Status:** DONE (PR #537)

## Problem
A band-1 ICT game finding letters/numbers on a friendly on-screen keyboard.
Kids know keys exist but haven't mapped where they live — they need to explore
a QWERTY layout and hear the key when they find it.

## Fix
New `KeyboardExplorerScene` — find-the-key on a real QWERTY keyboard:
- **The keyboard:** 3 friendly blue QWERTY rows (10/9/7 keys) with rounded
  "button" shading; a top number row 1–0 is added for number/mixed hunts.
- **Letter + number hunts:** a big yellow badge with the target key bounces at
  the top and the prompt speaks it ("Find the B" / "B খুঁজো" in BN). Lvl 1–2
  hunt letters, lvl 3–4 hunt numbers (single big number row), lvl 5–6 the
  whole keyboard mixed.
- **Speaks the key:** every prompt and every correct hit is spoken ("B!" /
  "৭!"); numbers display as Bangla digits (০১২৩৪৫৬৭৮৯) in the bn locale.
- **Feedback:** correct key flashes green + speaks the key; wrong key shakes
  red and re-speaks the target.
- **Round = K-key hunt:** find K distinct keys per round (K = 4/4/5/5/6/6 by
  level), no consecutive repeats.

Wired as skill `ict-keyboard` (band 1 ICT, c1-ict-2, class 1), game
`game-keyboard`, scene key `KeyboardExplorer`, bg "candy". i18n: 5 new kb*
keys (EN + BN).
