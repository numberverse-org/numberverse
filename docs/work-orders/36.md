# Work order #36 — Wrong-answer ledger + resolve-to-complete

**Issue:** #36 · **Branch:** feat/issue-36

## What
Persist every wrong answer per kid+skill; don't let a wrong drift away — the
app re-queues struggled skills and the parent can see exactly where help is needed.

## Changes (5-spot)
1. **store.ts** — `MistakeState { wrong, open, firstAt, lastAt, lastDifficulty }`,
   `mistakes` slice (key `${kidId}:${skillId}`, persisted via partialize), `recordWrong`,
   and `addEvent(correct)` clears `open` (a correct solve resolves the wrongs).
2. **wrongLedger.ts** (new) — module holds the current attempt context
   (kid+skill+game+difficulty); `record()` writes into the store. No scene touched.
3. **hints.ts** — `hintWrong()` calls `wrongLedger.record()` on EVERY wrong tap →
   33/33 drill scenes report automatically (the escalation ladder already reveals
   the solution at miss #3 → "make the solutions").
4. **App.tsx** — `wrongLedger.setContext(...)` when a drill starts, cleared on exit;
   `sessionForWorld()` prioritizes skills the kid has ever missed FIRST (resolve-
   to-complete); parent panel "Needs a little help" lists open/≥3-miss skills.
5. **styles.css** — parent-help block styling.
