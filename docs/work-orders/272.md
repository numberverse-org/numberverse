# #272 — Safety: instant pause (parent kill-switch)

**Status:** ✅ Shipped (PR #574)
**Priority:** low · guardrail

## Goal
A parent control that instantly pauses all games for a chosen kid with a restart screen.

## Done when
- [x] One-tap pause — "⏸️ Instant pause" block at the TOP of Learning controls (before Subjects): a single ⏸️ Pause / ▶️ Resume button per kid, red-tinted when active (`.btn.danger` / `.danger-ghost`)
- [x] Kid-safe message — the kid app shows a calm, night-sky "😴 A short learning break" screen (resting Nova, drifting ☁️⭐🌙, 💤) in the kid's language (EN+বাংলা) INSTEAD of any play screen — home, worlds, games, everything
- [x] Survives reload — `paused` lives in `KidSettings` (server) and the on-device `nv_kid_settings` cache, so the pause holds across reloads and offline; a lightweight 30s visible-tab poll lands a parent's mid-session pause instantly (no re-render churn otherwise); on resume the app drops the kid back to a FRESH home (the "restart screen") rather than resuming mid-game

## What shipped
- `apps/api/app/models.py` — `paused` (Boolean, server_default "false") on `KidSettings`, auto-migrated
- `apps/api/app/schemas.py` — `paused: bool = False` on `KidSettingsIn/Out`
- `apps/api/app/routers/kids.py` — `put_kid_settings` persists `paused`
- `apps/parent/lib/api.ts` — `paused?: boolean` on `KidSettings`
- `apps/parent/app/page.tsx` — `PAUSE_LANGS` EN/BN config; `DEFAULT_SETTINGS` += `paused: false`; the ⏸️ Instant pause block at the top of Learning controls
- `apps/parent/app/globals.css` — `.pause-block` (red-tinted when active)
- `apps/kid/src/api.ts` — `paused: boolean` on `KidSettings`/`KID_SETTINGS_DEFAULT` (cached with the rest → survives reload)
- `apps/kid/src/App.tsx` — `pauseTitle`/`pauseBody`/`pauseBackSoon` strings (EN+BN); the pause gate before every play screen (renders the 😴 break instead); a 30s visible-tab settings poll (`fetchKidSettings` → applies only when `paused` flips); `wasPaused` ref → resume returns to a fresh home + `cancelSpeech()`
- `apps/kid/src/styles.css` — `.pause-screen`/`.pause-sky`/`.pause-mascot`/`.pause-body`/`.pause-z`/`.pause-note` (reuses the break-screen drift/bounce animations — no new motion)

## Design notes
- The gate sits after ALL hooks and before the first screen return, so every screen (including the Phaser game) is replaced while paused — the game never mounts, so the loop genuinely stops.
- The poll is online-only-in-effect (offline `fetchKidSettings` falls back to the cached value, which already carries `paused`), visible-tab-only, and only re-applies settings when `paused` actually flips — no mid-play re-render churn.
- Parent pause outranks every kid-side override (quiet hours, break screens, Moni calls).
