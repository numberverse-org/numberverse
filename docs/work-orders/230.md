# #230 — Bar chart reading

**Status:** ✅ done

## Problem
Band-3 (ages 6–8) needed a data game answering how-many questions from
kid-friendly bar charts, with tap-the-bar answers, i18n clean.

## Fix
New Phaser scene `BarChartScene` (`apps/kid/src/game/BarChartScene.ts`):

- **6+ charts** — six kid-friendly emoji charts (fruit bowl, ocean, farm,
  space, garden, toys), 4 categories each. Emoji labels are language-neutral;
  the word under each bar (and in the question) localizes EN/BN.
- **Tap-the-bar answers** — each bar (emoji + bar + word column) is a tap
  target; the question ladder rotates: levels 0–1 "which is the MOST?",
  2–3 "which one has N?", 4–5 "how many 🍎?".
- **Unambiguous** — every chart's counts are distinct, so each question type
  has exactly one correct bar.
- **i18n clean** — localized header, question templates + speech lines EN + BN,
  Bangla digits for count badges and "has N" questions.
- Registered in engine + core catalog (`data-barchart`, band 3 math, 2.MD.10 /
  3.MD.3) + seed parity.
