# #18 — Parent: in-app Help card (iOS install + voice download guide)

## What
A collapsible ❓ **Help & setup** card in the parent portal covering the two
biggest parent questions, plus a stale-install self-check:
1. **Install on iPhone/iPad** — 5 steps (Safari → Share → Add to Home Screen).
2. **Download the Bangla voice** — accurate iOS (Spoken Content → Voices →
   Bengali) and Android (TTS → Install voice data) paths.
3. **Build-stamp check** — how to read the kid app's own version stamp
   (⚙️ Settings → About → "Numberverse · vX.Y.Z · <date>") and what a stale
   install means + how to refresh. Honest by design: the portal doesn't
   hardcode a version, so the guide can't go stale.

## i18n
