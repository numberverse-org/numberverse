# Work Order — #185: English alphabetical order race

**Status:** ✅ Merged via PR #512

## Problem
Band 1/2 reading needed the ABC-order skill — knowing words come in a set
order by their letters. Dragging 4-6 word cards into alphabetical order makes
the comparison visible and hands-on.

## Fix
New `AlphaOrderScene` (`apps/kid/src/game/AlphaOrderScene.ts`), band 2, scene
key `AlphaOrder`, skill `en-alphabet` (c2-english-11), game `game-alphabet`
(difficultyLevels `[4,4,5,5,6,6]` — 4 words early, 6 later).

**Mechanic — drag to ABC order, instant check (done-when):**
- **Levelled word sets (done-when):** 24 sets — 8× four words (all distinct
  first letters, band-1 easy), 8× five words (longer vocabulary, still distinct
  firsts), 8× six words (shared first letters like ant/apple, bear/bee/bird
  force a 2nd/3rd-letter comparison).
- The row is shuffled until it is NOT already alphabetical. The kid DRAGS a
  card to a new slot (Back.easeOut snap); step badges ১ ২ ৩ … sit above each
  slot in local digits.
- **Instant check (done-when):** after EVERY drop each card that now sits in its
  correct ABC slot glows green (and back to white when dragged away), so the
  kid sees progress live — and the round wins the instant the whole row is
  green. The words are then spoken in order ("apple, ball, cat, dog").
