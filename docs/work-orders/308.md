# #308 — CI: dependency-audit job (npm audit)

**Status:** ✅ done (merged — issue CLOSED)

## Problem

A contributor could add a dependency with a known HIGH/CVSS vulnerability and CI
would not care — only the license gate (#271) and secret-scan ran on deps.

## Done-when (from the issue)

- [x] **Audit step** — `scripts/audit-deps.mjs` runs `pnpm audit --json` in the
      new `dep-audit` CI job (parallel, after install).
- [x] **Fail on high** — any HIGH/CRITICAL advisory not explicitly allowlisted
      exits 1 (verified fail-closed by removing an entry).
- [x] **Allowlist reviewed** — every allowlisted advisory carries a written
      justification: the 9 `next` advisories (parent app is `output: "export"` —
      static, no server/route-handlers/middleware/server-actions → the server-side
      code paths never run; the Next 15 fix is a tracked follow-up), `vite`
      (dev-server only, never runs in production), `postcss` (build-time,
      transitive via next, fixed by the Next upgrade). WARNs (not fails) when an
      allowlisted advisory disappears so stale entries get removed.
