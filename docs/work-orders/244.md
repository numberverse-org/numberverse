# Work Order #244 — Parent: daily play summary

**Status:** DONE · **PR:** #558 · **Branch:** feat/244-daily-summary · **Merge:** main

## Problem
The portal opened on the family overview + weekly report — parents had to scan
numbers to answer the #1 opening question: "what happened TODAY?"

## Fix
A one-line "☀️ Today" card at the top of the dashboard (right after the progress
summary) with today's headline stats.

- **Today's headline stats** — rounds today, minutes played today (from the
  rolling weekly report's per-day buckets) and skills mastered today (new
  `mastered_today` field: ≥80% mastery AND last practiced since local midnight).
- **Refresh daily** — the weekly report is re-fetched with the dashboard; the
  card keys off today's date so a fresh open always shows today.
- **Offline-generated** — the headline is derived entirely from the `weekly`
  state already loaded with the dashboard. No extra network call, no cloud.
  An empty day shows a friendly "Nothing yet today 🌱" nudge instead of zeros.
