# #226 — Odd & Even sort game

**Status:** ✅ done

## Problem
Band-2 (ages 4–6) needed a parity game: sorting numbers into odd/even with a
pairs visual aid, in the 0–100 range, with clean i18n (EN + BN) from the start.

## Fix
New Phaser scene `OddEvenScene` (`apps/kid/src/game/OddEvenScene.ts`):

- **Pairs visual aid** — the number renders as 2-column dots; even = every dot
  has a partner, odd = the last dot is a lone leftover (highlighted orange).
  For numbers > 20 the dot strip shows a *representative* pairing pattern (same
  parity) so the lone-dot lesson never lies while the big numeral carries the
  question.
- **Difficulty ramp** — levels `[10, 20, 30, 50, 80, 100]`; early levels cap the
  question at ≤9 so the grid stays readable, later levels open the full 0–100
  range.
- **Odd/Even buttons** — two large tappable circles (🦉 Odd / 🥚 Even) via
  `answerRow` + `modernAnswerButton`; wrong taps use `hintWrong` with inline
  EN/BN coaching ("Count the pairs — is one left alone?").
- **Framing** — `frameText("oddEvenPrompt", …)` rotates 3 phrasings per round
  (anti-boredom #337), all EN + BN.
- **Localized digits** — the big numeral renders Bangla digits (৫০) in bn mode.
- Registered in `engine.ts` (import + scene array), core `skills.ts`
  (`odd-even` skill, `game-oddeven` GameConfig, `GAME_SCENES['game-oddeven']`),
  and `seed.py` SKILLS_SEED (audit ③ parity).
