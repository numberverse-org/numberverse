# Work order #341 — Moni: session-length recommendation surfacing
> milestone: v26 — Kotha & adaptive · branch: `feat/issue-341`

## Goal
Moni suggests session lengths per kid and the app reflects them.

## Done when
- [x] Per-kid hint
- [x] Soft, not enforced
- [x] Offline

## What shipped
- **Parent Moni card**: a new "Best session" cell shows Moni's per-kid
  recommendation (`moni.plan().sessionLengthHint`, which is the measured
  attention `fatigueThreshold` when known, else the sensible default 12).
  Fully local — computed from the store's own Moni profile, no network.
- **Kid done screen**: a soft pill after a session — "Moni saw you stay sharp
  for ~N rounds — keep going or take a break, your call 💛" (EN + BN). It's a
  suggestion only: the keep-going / play-again / home buttons all stay, so
  nothing is enforced. Only appears after a kid has ≥4 recorded rounds.
- Reuses the pre-registered but previously unwired `moniSessionLength` i18n
  key, plus a new `moniSessionHint(n)` copy in both languages.
