# Work Order 203 — Math: symmetry mirror game (complete the mirror half)

**Issue:** #203
**Status:** DONE (PR #530)

## Problem
Band-2 kids can see a picture but the "fold it in half and both sides match"
idea needs to be something they DO. A mirror-completion game makes symmetry a
puzzle: half the picture is given, the kid finds the half that folds onto it.

## Fix
New `SymmetryMirrorScene` — complete the mirror half of pictures:
- **13 designs** (≥10 as required): heart, pine tree, cup, house, tulip,
  diamond, umbrella, rocket, ghost, star, mushroom, castle, apple. Each is
  defined by its LEFT half only (8×6 pixel mask); the true right half is
  derived as the exact mirror, so the game NEVER shows a broken picture.
- **Fold-line visual:** a dashed gold line runs down the mirror axis; the left
  half is drawn solid beside it and a faint frame marks the blank right area.
- **Tap the mirror half:** the kid picks the correct right half from 4 cards,
  each showing a candidate right half. Distractors are real mirror-halves of
  OTHER designs plus the classic "put the left half on the right" mistake —
  never mangled shapes, so wrong answers teach shape-comparison, not guessing.
- Correct → the whole symmetric picture snaps together with a pop + gold ring
  and the fold is spoken (sySpeak). Wrong → green ring reveals the right card
  and the true mirror appears faint in the picture (syHint).

Wired as skill `en-symmetry` (band 2 math, c3-math-15, class 3), game
`game-symmetry`, scene key `SymmetryMirror`, bg "candy". i18n: 6 new sy*
keys (EN + BN). Bangla digits for the BN locale.
