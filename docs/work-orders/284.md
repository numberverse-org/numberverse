# #284 — Mastery mystery reward boxes

**Status:** ✅ done (PR pending → issue CLOSE)

## Problem

Mastering a skill deserves a fun little win beyond the card + confetti.
Acceptance: **box on mastery** · **reward within cap** · **kid-safe**.

## Fix

A **🎁 Mystery Box** card on home: every mastered skill that hasn't been boxed
yet appears as an unopened box (newest mastery first). Opening pays **2–5
coins**, always inside the daily anti-grind cap — no real money anywhere.

- **Store** (`store.ts`) — `NovaState.boxes: string[]` persists the opened-box
  skill ids; `novaOpenBox(kidId, unclaimed) → { skillId, coins }`:
  - no unclaimed box → `{ skillId: null, coins: 0 }`
  - daily cap already full → `{ skillId, coins: 0 }` — the box WAITS for
    another day (never forced below the cap, no over-grind)
  - otherwise awards 2–5 coins (min(reward, cap − earnedToday)), marks the
    box opened, and returns the coins for the UI to cheer
- **UI** (`App.tsx`) — `unclaimedBoxes` = mastered skills (via
  `skillMastered`) not in `storedBoxes`, sorted newest-first. A pulsing
  🎁 card (after the pet card) shows the count + an **Open** button:
  coins granted → `tada()` + spoken cheer in the app's language; cap-full →
  a warm "come back tomorrow" line; box stays.
- **i18n** — 5 `Strings` entries EN + BN (`boxTile/Hint/Open/CapSpeak/
  RewardSpeak`), Bangla digits via `bnNum`.
- **CSS** — `.box-card` (pink/gold, pulsing gift) in styles.css.
- **Offline** — local store only.
