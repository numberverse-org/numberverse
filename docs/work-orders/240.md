# Work Order #240 — Parent: compare two kids side-by-side

**Status:** DONE · **PR:** #556 · **Branch:** feat/240-compare-kids · **Merge:** main

## Problem
With multiple kids on an account, parents eyeball two mastery tables side by
side to see who's ahead — no single view compares kids on the same metrics.

## Fix
New "⚖️ Compare two kids" card on the parent dashboard (after Needs a little
help), shown only when the account has ≥2 kids.

- **Pick two kids** — two dropdown pickers with an animated "vs" in between;
  defaults to the first two kids on the account, remembers your picks while the
  page is open.
- **Per-metric columns** — a metric-by-metric table (Skills mastered, Current
  world, Minutes this week, Rounds this week, Correct % this week, Days active,
  Mastered this week, Skills in progress). The leading kid per metric is
  highlighted in gold, so the comparison reads at a glance.
- **Offline** — every metric is derived purely from the `mastery` + `weekly`
  state already loaded with the dashboard (current world = the highest band of
  any skill the kid has attempted, via the `@numberverse/core` catalog). Zero
  new network calls.
