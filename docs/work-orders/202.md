# Work Order 202 — Math: 2D → 3D shape pairing (flat faces & solids)

**Issue:** #202
**Status:** DONE (PR #529)

## Problem
Band 2/3 kids know "a cube has squares", but the bridge from FLAT faces to
SOLID shapes is the exact jump where spatial reasoning starts. They need a
game that pairs each solid's 2D face with its 3D body — and a rotating preview
so the "hidden" back faces stay visible (you can't see a cube is made of
squares from one photo).

## Fix
New `SolidMatchScene` — match flat faces to solid shapes:
- **6 solids** drawn in pseudo-3D (front/top/side faces with depth): cube,
  cuboid, cylinder, sphere, cone, square pyramid.
- **Rotating preview:** every drawn solid sits on a turntable whose scaleX
  oscillates 1 → −1 (cos-tween), so it visibly spins and shows front + back.
  The big question preview and all four answer cards spin.
- **Two alternating question modes** (qIndex parity):
  - SOLID→FACE: "Which flat shape is a face of the {solid}?" — big solid
    spins above 4 flat-face cards (square / rectangle / circle / triangle).
  - FACE→SOLID: "Which solid has this flat face?" — big flat-face stamp
    above 4 solid cards drawn from all 6 (correct solid + 3 distractors).
- **Pairings taught (class-3 standard):** square→cube, rectangle→cuboid,
  circle→cylinder, triangle→pyramid. Sphere + cone are always distractor
  solids (they have no flat faces) so the kid learns WHY.
- Correct → gold "Solid match!" float + spoken "{solid} has {face} faces".
  Wrong → the correct answer is revealed as a green label.

Wired as skill `en-solidmatch` (band 3 math, c3-math-14, class 3), game
`game-solidmatch`, scene key `SolidMatch`, bg "magic". i18n: 15 new keys
(sf*, solid*, face* — EN + BN). Bangla digits + Bangla solid/face names for
the BN locale. All six solids are configurable name keys (`solidCube`…
`solidPyramid`), so a new country/language pack only adds dict entries.
