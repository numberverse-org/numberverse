# Work order #381 — Voice: Bangla TTS mispronounces embedded words
> milestone:  · branch: `feat/issue-381`

## Goal
The Bangla neural voice (Piper bn_BD) reads Latin words (kid names, "Nova",
"Moni", game titles) and Western digits as garbled English noise. Make every
Bangla line sound like a Bangla speaker said it.

## Done when
- [x] Bangla text normalized before synthesis
- [x] Known app vocabulary maps to Bangla
- [x] Digits spoken as Bangla number words

## What shipped
- **Bangla normalizer** (`apps/kid/src/game/speech.ts`): `speak()` now runs
  every Bangla line through `bnNormalize()` before the neural/web engine gets
  it. Three passes:
  1. **Digits → Bangla number words** — `87` → "সাতাশি", `2.5` → "দুই দশমিক
     পাঁচ" (via the existing `bnNumber()`), so the voice never reads a bare
     Western digit.
  2. **Known app vocabulary → exact Bangla** — `BN_APP_WORDS` maps Nova →
     নোভা, Moni → মনি, Google → গুগল, YouTube → ইউটিউব, English → ইংরেজি,
     Count → কাউন্ট, Pop → পপ.
  3. **Latin-word fallback → Bengali-syllable transliteration** —
     `bnTransliterate()` reads any leftover Latin word the Bangla way:
     consonant+vowel folds into consonant+vowel-matra, doubled vowels become
     one long matra ("Neel"→নীল), digraphs map to one Bengali sound
     ("Shyam"→শ্যাম), word-final consonants drop the halant ("Rahim"→রাহিম).
     Covers kid names, plant titles, badge titles — anything a parent typed
     in Latin letters.
