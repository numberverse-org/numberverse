# Work Order — #166: Bangla letter vs sound discrimination (অ-আ-ক-খ)

**Status:** ✅ Merged via PR #493

## Problem
Band 1 learners confuse letters that sound alike (ক/খ, প/ফ, স/শ). Recognizing
a sound and mapping it to the right glyph is a core phonological-awareness step
that no existing band-1 game isolates.

## Fix
New `LetterSoundScene` (`apps/kid/src/game/LetterSoundScene.ts`), band 1, scene
key `LetterSound`, skill `bn-lettersound` (c1-bangla-3), game `game-lettersound`
(difficultyLevels `[2,2,3,3,4,4]` = tile count).

**Mechanic — sound-first:**
- A letter sound plays FIRST when the letters appear (speak bn, 320ms in).
- The kid taps the matching letter among its confusable twin + distractors
  (ক/খ side by side, then letters from other pairs).
- 🔊 replay button re-hears the sound any time; wrong taps re-play it too.
- Correct: pop + correctCelebrate + the letter is re-spoken.
- Wrong: hintWrong retires the tile (killOption) with a gentle bilingual
  "listen again" nudge; the target sound re-plays 500ms later.
- No-repeat rule: the same target never appears twice in a row.

**Data:** 14 confusable pairs (28 letters) — 11 aspirate consonant pairs
(ক/খ … ড/ঢ) + 3 vowel pairs (অ/আ, ই/ঈ, উ/ঊ). EASY pool (levels 0-1) =
ক/খ, প/ফ, স/শ, অ/আ, ব/ভ.
